# 入力から8頂点を作る立方体の作図ドリル

目的は、指定道具で入力を紙上の8点へ移し、どの段階で迷い・誤差が出るかを確認すること。効果や必要な練習量を検証したドリルではない。

1. [手順書](../../docs/cube-construction-manual.md)と[空の作業表](../../assets/cube-projection-research/blank-worksheet.md)を使う。最初は[記入済み例](../../assets/cube-projection-research/worked-examples.md)の正面、次に斜め、最後に上面を見せる例を選ぶ。
2. 入力を記入し、角度成分と3半辺から8頂点を自分で求める。正解表を見るのは各段階の照合時にする。
3. 割算で紙上座標を出して描く。時間を測れる場合は準備と描画を分けて記録し、未測定なら空欄を0にしない。
4. 同じ入力で視線法を試す場合は、[補助図の手順](../../methods/drafts/cube-ray-construction.md)へ進む。縮尺と紙の枚数を残す。
5. 迷った箇所・転記・消し直し・最大座標差を記録する。大きなずれがあれば入力・途中値・最終点の順で戻る。

1回で何枚・何分行えばよいかは未設定。まず1条件を最後まで実行できるかを確認する。人による実施前のため状態は `draft` のままにする。方法比較や後日の保持・転移を行う場合は、別途実施前の計画を立てる。既存の箱比率計画の時間や枚数は転用しない。
