## 座標と再生成

[generate.py](generate.py)をPython 3で実行すると2点のSVGを生成する。標準ライブラリのみを使う。

```sh
python3 assets/torso-construction-comparison/generate.py
```

右手系のxを横、yを上、zを前とし、方位30度・仰角15度の平行投影。角度は説明用で、教材指定の数値や人体の可動域ではない。破線は隠れる辺。青は上側、黄は下側で、素材の色ではない。

洞田側の基準箱を幅1・高さ1・奥行き2/3、補助箱を高さ3/4として生成する。変形図の底面は幅4/3・奥行き2/3とし、二分すると正方形2つになる。その底面だけを後方へ奥行きの1/4ずらす。上面の座標は不変。これらは構築上の値であり、画面上の幅／高さ比や生体骨盤の標準比率ではない。

Robo Bean側の幅・高さ・奥行き・間隔はすべて説明用に選んだ値。個人差を示す教材から人体の固定寸法を導いていない。左右の胸上端の画面座標も一致させていない。比較するのは**箱の役割と接続**であり、同一人体の形状誤差ではない。

PNGは同梱NodeのSharpでSVGを1440×800に描画して生成した。SVG内に外部画像・スクリプト・フォント取得はない。別環境では日本語フォントにより字幅が変わるため、再出力時にラベルを確認する。

## 点検記録

2026-10-02、生成コードの座標検査で補助箱高さ、底面の二つの正方形、底面の後方移動量、上面不変を確認。生成したPNG2点をAIが実画像で確認し、日本語ラベルの欠け・図との重なり・枠外の文字がないこと、各面・隠れ辺・段階間の向きが説明と対応することを確認した。SVG2点のXML解析、ローカル参照も点検。

人体の自然さ、初心者の理解、手順による学習効果は未評価。PNG目視点検は専門家の査読や人による使いやすさの評価ではない。側屈・ねじれを比較する完成模式図は今回作成していない。
