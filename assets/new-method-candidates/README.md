# 新メソッド候補を説明する作図

[解説原稿](../../reports/new-method-candidates/manuscript.md)用の独自の説明図。SVGが印刷用、PNGが通常のMarkdown表示用。`make_figures.py` で再生成する。

| 図 | 説明すること |
| --- | --- |
| m1-steps | 上の高さを四分割し、同じ一区間を下へ三つ取る |
| m1-feedback | 40/30という目標、40/34という仮の描画、次の描画で短くする方向 |
| m2-conditions | A：参照あり、B：観察後に隠す、C：定義は参照して別視点を描く |
| m2-recall | 同じ模型・視点で、下箱だけ右へずれた仮の出力を比べる |
| m2-view-change | 模型を固定して見る方向だけを変える |
| m3-line-roles | 外形、軸、断面の回り込みという線の役割 |
| m3-connection | 玩具の接続という設計条件と、実際の線の対応 |
| m4-transfer | 部分練習で確認した接続を別ポーズの玩具へ使う |

M1の数値は説明用に選んだ値。M2の二箱は [既存の模型定義](../construction-geometry/models.json) の `two-boxes` を使い、既存の `mesh`・`project` 等で平行投影した。A/B説明図の仮の再生は下箱だけを画面上で27px右へ移動し、上箱の位置は保っている。人の実測データではない。

視点変更は方位25度・仰角15度から方位65度・仰角15度。既存の未提示評価視点E1（65度・20度）とは異なる説明専用の組合せで、既存の刺激や評価画像は書き換えていない。この別冊を見た人には、本書の65度・15度の図を「初めて見る角度」として出題できない。

M3・M4の箱と棒は玩具の模式図。赤点は玩具の設計上の接続位置であり、人体の肩関節を示さない。すべての図は説明目的で、学習効果や人の実描画の証拠として使わない。
