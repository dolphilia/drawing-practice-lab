# 共有素材

このディレクトリの内容は Git で追跡します。必要な素材を選び、元の制作ファイルや大量の練習画像はローカルで保存します。

| 保存先 | 用途 |
| --- | --- |
| `worksheets/` | 印刷・配布して使う練習シート |
| `evidence/` | 実験で共有する比較画像、評価例 |

素材ごとに同名の `.md` メモを添えるか、参照元のドリル・実験本文に次を記載します。

- 作者・作成日、または取得元の URL と確認日
- 自作 / 外部資料の区別と、確認した共有・再利用条件
- 対応する文書、制作条件、画像を加工した場合はその内容

表示・印刷に必要な大きさに整え、巨大な原本を不用意に追加しないようにします。共有素材が増えて通常の Git 管理が負担になった段階で、外部ストレージや Git LFS を検討します。
