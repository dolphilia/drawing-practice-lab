# 半辺の表と奥行きの割算で立方体を作図する

## 使う条件

指定道具と四則演算で、位置・姿勢・辺長が与えられた立方体を平面へ中心投影する。全頂点が視点の前方にあることが必要。近い頂点のZが小さいと、わずかな入力誤差が拡大する。図全体を紙に収める倍率は計算前に決める。

数学的には任意の相対姿勢を扱う。人にとって容易か、速いか、練習効果があるかは未確認。既存の中心投影を手作業へ整理した草案であり、投影原理の新発見ではない。

## 入力と前処理

辺長a、中心C、角度α・β・γ、画面距離f、紙上倍率mを[空の作業表](../../assets/cube-projection-research/blank-worksheet.md)へ書く。世界座標から始める場合は[入力仕様](../../research/topics/cube-projection-input-spec.md)の逆変換を先に行う。

角度ごとに半径80mmの円を描く。右へ向く半径を0度、反時計回りを正として分度器で角度を取る。端点から横軸・縦軸へ垂線を下ろし、符号付きの横距離・縦距離を読む。80で割ったものがc・sになる。0・90・180・270度は0・±1を直接使える。30・45・60度は三角定規で設定できるが、成分は同じように読む。

研究用の既定値は距離を0.5mm刻みで読み、c・sは小数6桁まで保存する。これは0.5mmを正確に読めるという保証ではなく、丸め仕様である。曲線の交点や線の太さによる差は別に評価する。円が紙に入らない場合に半径を変えるなら、その半径で割り、誤差仕様も変更する。

## 3本から8頂点を作る

1. h1=(a/2,0,0)、h2=(0,a/2,0)、h3=(0,0,a/2)を書く。
2. 各半辺に[入力仕様の3回転](../../research/topics/cube-projection-input-spec.md)を適用する。XとZ、次にYとZ、最後にXとYを組にする。各組の新しい値は、両方を計算し終わってから置き換える。
3. 最後の半辺成分を0.001mm単位まで書き留める。
4. 符号表に従い、C±h1±h2±h3で8点のX・Y・Zを求める。途中でCを回転させない。
5. Zが0以下の行があれば止める。近い行のZが丸め幅と同程度なら、姿勢・距離を変えるか精度を上げる。

確認用に、向かい合う頂点の座標の和が2Cになるかを見る。これは転記ミスを検出する一つの条件で、直交性まで保証する検査ではない。

## 投影と仕上げ

各行でk=f÷Zを小数6桁まで求め、u=m×k×X、v=m×k×Yを計算する。最終座標は0.1mm単位で記録する。紙に原点を取り、uが右、vが上の符号付き座標として点を打つ。12辺を[頂点番号](../../research/topics/cube-projection-input-spec.md)どおりに結ぶ。

Zが**同一であると入力・計算から分かる行**はkを再利用できる。異なるZを見た目でまとめない。3半辺の対称性は正確な省力化として採用する。一方、半辺の成分を「きれいな数」に直すと立方体の等長・直交条件を変えるので、近似として別に扱う。

線の見える・見えないを分ける必要があるときは、面の中心Fと外向き単位法線nの内積F·nを計算する。負なら視点から表を向く面、正なら裏を向く面。辺に接する2面の少なくとも一方が表なら実線、両方裏なら破線とする。0付近の面は線が重なる退化条件として扱い、判断が難しければまず全12辺を薄く描く。

## なぜ任意姿勢に使えるか

3回転は長さ・直角を保つ。直交して長さa/2の3半辺から符号を組み合わせれば、各辺がaの立方体ができる。視点から(X,Y,Z)へ向かう線は、Z=fで(fX/Z,fY/Z,f)を通る。よって、視点の前方にある各頂点に同じ操作を行えば中心投影になる。

円の読み・成分の丸めは、この理想的な前提を少し変える。理想値と丸めを含む値を同じ「正確」と呼ばない。
