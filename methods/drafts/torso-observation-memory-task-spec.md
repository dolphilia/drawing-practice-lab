# 体幹の観察構築・記憶再生・未提示角度：課題仕様草案

**3種類の成果を混同せず記録するための実施前仕様。** 文書としての設計は完了した。後続の整備で[幾何学素材2モデル・12視点](../../assets/construction-geometry/README.md)と計算検査を作成したが、人体の刺激セット、人による課題の実施、採点一致、実行負担、練習効果は未確認。既存の[箱比率実験](../../experiments/2026-10-02_torso-ratio-pilot.md)とは別仕様で、条件・閾値を変更しない。

## 原理の仮説と対象

体幹の主要な量・目印・相対的な向きを選び、参照の有無と照合の時点を分けると、どこで誤ったかを説明しやすくなるという仮説。成人の描画学習を想定するが、技能水準による実行可能性は未調査。

手順の出典は[洞田とProkoの比較](../../research/comparisons/torso-construction-worked-comparison.md)、評価条件の設計資料は[観察・記憶・照合の根拠](../../research/learning-science/observation-memory-feedback.md)。両教材の箱の意味は異なるため、共通の比率得点で優劣を決めない。

## 共通の入力・保存条件

各刺激にID、出典・利用条件、画像寸法、表示条件、対象の既知／未知、指定方法と版、参照できる目印を付ける。3D刺激ならモデル・投影・カメラ・ポーズの版も保存する。人体画像の見えない点は「推定」として分け、正解点を創作しない。

各試行は次を保存する仕様とする。今回は空の実測記録や架空の描画を実データとして作らない。

| 記録項目 | 定義 |
| --- | --- |
| 条件 | 課題A/B/C、方法名・版、刺激ID、練習／評価、参照と補助の可否 |
| 時間 | 観察、描画、照合、修正を分離した実時間。中断も記録 |
| 原出力 | 照合前の描画、本人が置いた基準点ID、任意の説明。後から上書きしない |
| 照合 | 提示した正解情報、選んだ誤差の種類、照合した箇所 |
| 修正 | 修正版または次の描画を別ファイルにする。修正前後の関係ID |
| 欠測・逸脱 | 点が特定できない、参照の再閲覧、外部支援、時間未記録など。0点とは別扱い |

練習時間・反復数・保持間隔・合格閾値は未設定。既存論文の分数を推奨量として移さない。将来実施する場合に、事前の目的と負担確認に基づき版を更新する。これは今回の文書完成を待たせる条件ではない。

## A：参照ありの観察構築

**目的：** 見える目印と面の向きを、選んだ単純化へ対応付ける。

**入力：** 利用可能な人体参照と一つの方法の説明、または正解の投影を定義できる独自幾何学モデル。人体画像と幾何学モデルを同じ得点群へ混ぜない。指定方法の手順書を許可する練習と、補助を外す評価を分ける。

**手順：** 参照を表示 → 見える目印をID付きで選ぶ → 量と面の向きを構築 → 照合前を保存 → 参照と並置し、指定した差を記録 → 修正を別保存。重ね合わせを使う場合はその事実と変換を記録する。

**成果物：** 参照ID、構築図、基準点対応表、修正前後、観察・照合の時間。

**評価候補：** 参照上で同定できる点の位置、面の方向、重なり関係、方法内の操作の整合。写真から直接測れない三次元の厚みや裏側を正誤判定しない。点の選択の妥当性と人体らしさは別問題。

## B：参照を閉じた同一視点の再生

**目的：** 観察した同じ見え方の配置を、参照なしでどれだけ再生できるかを区別する。

**入力：** Aと対応する種類の刺激。観察段階だけ参照を提示し、再生中は参照・手順書・以前の描画を非表示にする。観察中に描くかどうかも条件として固定する。最初の草案では観察のみとし、観察模写を追加する場合は別条件にする。

**手順：** 刺激を観察 → 参照を閉じる → 同一視点で再生 → 照合前を保存 → 参照を再提示して差を記録 → 修正を別保存。閲覧のやり直しは逸脱として残す。練習では照合を許すが、評価の最初の出力には正解を見せない。

**成果物：** 刺激ID、観察終了から再生開始までの間隔、参照なしの原出力、照合・修正の記録。

**評価候補：** 同一視点での基準点配置・相対的な向き・欠落の種類。Aと同じ測定式を使う部分でも、条件の意味は別。低成績を記憶だけの問題と断定しない。観察・理解・運筆も出力へ影響する。

直後のBは短期の再生成績。後日の同じ課題はその像の保持を含み、広い描画技能の保持とは等しくない。技能保持を見る場合は、後日の参照条件をそろえたAや、新刺激の成績も別枠で定義する。

## C：未提示角度からの幾何学的構築

**目的：** 既知の立体の構造を、練習していない視点へ適用できるかを調べる設計。

**入力：** 形状が一意に定義された独自の立体モデル、寸法または形状定義、投影方式、目標カメラ。練習視点と評価視点の集合を分ける。**写真1枚から見えない人体を唯一の正解として採点しない。** 今回の比較SVGは役割説明図であり、そのまま人体の正解刺激にはしない。

**手順：** 許可した視点・立体情報を提示 → 未提示の目標視点を指定 → 指定条件で構築 → 原出力を保存 → 同一モデル・同一カメラで算出した投影と比較 → 修正を別保存。

寸法・モデル定義を描画中にも提示する条件を初期仕様とする。目標視点の完成投影は照合まで隠す。モデル定義まで隠すと立体の記憶が加わるため、別条件として版を分ける。

**成果物：** モデル版、使用済み視点一覧、目標カメラ、構築図、対応頂点、正解投影、照合記録。

**評価候補：** 対応頂点の投影誤差、面の向き、隠れる辺と重なる順序。対称形で頂点が曖昧なら識別印等を刺激側で定義する。形状・姿勢・カメラを同時に変えた場合は、それらを一つの「角度転移」にまとめない。

この課題が成功しても、幾何学モデルにおける視点変更の成績である。新しい人体・筋肉・皮膚・衣服・演技への転移は別の問いとして残す。

## 測定候補と誤差の扱い

| 指標 | 対応する技能・課題 | 計算上の注意 |
| --- | --- | --- |
| 対応点の位置誤差 | A/Bの見える点、Cの既知頂点 | 正解側の固定長Lで `||p_draw − p_ref|| / L`。紙面位置を課すか、平行移動だけ許すかを事前定義 |
| 軸方向の角度差 | A/Bの画面内方向、Cの投影軸 | 方向付き軸と向きなしの線を区別。短すぎる軸は欠測。2D線の角度から3D関節角を逆算しない |
| 比率誤差 | 同じ方法内で意味が固定された二長さ | `abs(log(r_draw / r_ref))` などは候補。正の非ゼロ値のみ。同じ名称でも異なる範囲を測らない |
| 重なり関係 | 可視面・前後順が確定するC、限定したA/B | 正解側で判定可能な組だけ数える。写真で不明な組を誤りにしない |
| 修正前後の差 | 照合への対応 | 練習中の修正能力。後日の補助なし成績とは別に報告 |

尺度・回転・せん断を合わせる前処理は、測りたい誤差を消すことがある。元座標を保存し、位置合わせ前後の指標を混同しない。自動測定を実装しても、どの線・点を読むかの妥当性が自動で証明されるわけではない。総合点の重みや改善判定閾値は設けていない。

## 比較する場合の条件と今回の完了範囲

AとBの練習効果を比べるなら、両群共通の評価課題、題材の重複、支援、フィードバック、配分時間、順序を事前に決める。自由閲覧のAと短時間観察のBでは記憶以外の条件も変わる。総時間を同じにしても工程別の時間は異なるため、全て記録する。方法の知識だけを変えたい比較と、参照の有無だけを変えたい比較を一度に混ぜない。

机上で確認済みなのは、入力・提示・保存・評価候補の対応、参照を閉じる時点、修正前を保存する条件、正解を定義できない対象を除外する条件である。採点一致、操作負担、刺激難易度、必要量、学習効果は未実測で、後続の人の試行に属する。今回それらの確認を求めず、`draft` のまま保存する。
