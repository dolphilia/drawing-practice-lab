# Ruskinの点から組み立てる透視図法

[The Elements of Perspective](https://www.gutenberg.org/files/60816/60816-h/60816-h.htm)、GutenbergのLibrary Edition。収録版の刊年は今回未確定。初版年で代用しない。

Introduction（とくにpp.7〜9）、Problem I〜II（pp.10〜16）、Problem IIIの冒頭を本文で確認した。図4・5は後続作業で画像を取得して本文と照合した。図6・7自体は未精査。

対象の奥行き・左右・高さを指定して点を投影し、その点を結んで線を作る順序を説明している。導入では画面や視点に関する条件を明示する。一般化する際は、原典が置く垂直な画面の前提を確認する必要がある。

当研究では「まず8頂点の位置を決める」という基準法の歴史的な参照にする。任意傾斜への展開は別途導出・検算する。教材の手順であり、容易さや学習効果の実測は今回確認していない。
