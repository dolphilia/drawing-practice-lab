# レオナルド手稿の編訳：記憶描画の照合と動きに応じた解剖

## 出典・確認範囲

[The Notebooks of Leonardo Da Vinci — Complete、Project Gutenberg版](https://www.gutenberg.org/cache/epub/5000/pg5000.html)、Jean Paul Richter訳。Vol.1の項目483–485、488–490、530–532の英語本文と周辺の編集注を確認。イタリア語手稿・原図・異訳との校合は未実施。

`published: 1888`は取得版の標題・メタデータの年。序文末尾の日付は1883年4月。レオナルドの手稿執筆年でも、生前にこの題名の本を出版した年でもない。章番号はこの編訳に従う。

## 確認した提案

| 項目 | 内容（当リポジトリによる要約） |
| --- | --- |
| 483–485 | 遠近・比率、優れた手本や立体・自然からの描画、師の批評を含む学習順序 |
| 488–489 | 動作に応じて働く筋を理解する。一律にすべての筋を強調する描き方を戒める |
| 490 | 屋外の動作を頭の丸や四肢の線などで簡略に記録し、帰宅後に展開する |
| 530 | 鏡像、休止、距離を取った観察で自作の誤りを見直す |
| 531 | 覚えたと思う対象を見ずに描き、透明な面の手本と重ね、誤った箇所を見直して描き直す |

短い原文引用：**“test it by drawing it without the model”**（531、英訳文）。当リポジトリ訳：手本を見ずに描いて確かめる。

## 信頼性・適用の限界

古い手稿の編集・翻訳を経た提案で、本人の日本語発言のように引用しない。生理学用語・説明には時代的制約がある。筋肉の教材として使う場合も、現代の解剖学上の正確さをこの史料だけで保証しない。

記憶描画と比較の循環が記されていることは確認できる。しかし、現代の検索練習研究と同一の介入・効果が検証されたわけではなく、保持間隔や最適回数も指定できない。

## 応用仮説

透明なガラスの代わりにデジタルの重ね合わせを用い、差を記録する試行が考えられる。媒体の置き換えと評価設計は当リポジトリの提案。手本を記憶できたかと、未知のポーズへ応用できたかは別に調べる。
