# 寺田克也：構造を見る習慣と学習歴の自己説明

## 出典・確認範囲

[AMG掲載のインタビュー](https://www.amgakuin.co.jp/archives/1160)、2008-05-01。「プロになる前」の質問から、見る訓練、砂糖入れ・信号の例、幼少期の描画対象までの本人回答を確認。学校の広報媒体で、取材の生データ・聞き手名は確認できない。

補足：[季刊エス・SS公式「寺田克也ココ10年展 インタビュー」](https://www.s-ss-s.com/c/teradakatsuya10)、Web公開2014-09-01、記事が扱う展覧会は2013年。展示・下絵・デジタル修正に関する本文を確認。

## 学習についての本人報告

| 要約 | 該当箇所 |
| --- | --- |
| 学生時代に大量の完成作を描いたという聞き手のイメージを、そのまま認めてはいない | AMG「プロになる前」の応答 |
| 中高生の頃、描きたいバイクの資料が手に入りにくく、日常の物を覚えておこうとした | AMG、バイクの回想 |
| 材質、開き方、蝶番、部品の取り付け方に注意した。色の並びを正確に思い出すこととは区別する | AMG、砂糖入れ・信号の例 |
| 頭の中で形を取ることが訓練になったのではないか、と振り返る | AMG、観察の説明の結び |

短い原文引用：**「『見る訓練』はしてたような気がします。」**（原ページでは内側の括弧は「」）。回想の留保を落とさないため、この語尾も残した。

補足記事では、下絵に鉛筆を使うこと、複数の紙をつないだ絵の継ぎ目をデジタルで修正したことを本人が話している。「優れた描き手は修正しない」という推測とは両立しない制作例である。

## 信頼性・適用の限界

幼少期・学生時代の回想であり、練習日誌や前後比較ではない。控えめな語りを額面どおり「練習不要」と解釈することもできない。仕事の要求、過去の描画、観察、他作家からの影響を分離した効果量はない。練習の分数・総量・上達に必要な期間は不明。

## 応用仮説

対象について「何が何に接続するか」「どこが動くか」を説明してから描く候補。形状の正確さと、機能的にもっともらしい創作とは評価を分ける。
