# ローカル画像の保存方針

練習画像・参考画像などを置くディレクトリです。**中身は Git で追跡しません**（この README と `.gitkeep` は例外）。クローンや Git の履歴からは画像を復元できないため、残したい画像は別途バックアップします。

| サブディレクトリ | 用途 |
| --- | --- |
| `references/` | 手元で参照する資料画像 |
| `methods/` | メソッドの説明用画像 |
| `exercises/` | ドリルの見本画像 |
| `experiments/` | 検証の前後比較画像（`YYYY-MM-DD_name/` ごとに分ける） |
| `logs/` | 日々の練習画像 |

## 文書との対応

- 実験ごとのフォルダに `before-01.png`、`after-01.png`、`retention-01.png` など時点・試行が分かる名前で保存する。
- 元画像は上書きせず、比較用の加工画像は別名で保存する。
- 文書には画像の保存先、制作日、題材・条件、評価結果を記載する。
- Git 管理外の画像をリンクする場合は「ローカル限定・共有先では表示されない」と明記する。
- 比較の数値や観察は本文にも残し、画像だけを検証の根拠にしない。

`experiments/` 直下の文書からは `../images/experiments/`、`logs/YYYY/` からは `../../images/logs/` の相対パスで参照します。

## 共有する画像

共有して読み返すための自作の図や比較画像は、必要なものを選んで Git 管理対象の [assets/](../assets/README.md) に置きます。練習画像全体の除外方針は維持します。

外部資料は出典と利用条件を記録します。再配布条件を確認していない資料本体・スクリーンショットは共有素材に入れず、資料メモから原典へリンクします。
