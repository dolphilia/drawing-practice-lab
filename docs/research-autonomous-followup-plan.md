# 人体の単純化と記憶描画の追加調査計画

作成・更新：2026-10-02。計画作成後、公開資料に限定した調査・図解・設計を完了。状態と成果物は「保存先と進捗」で管理する。

既存の調査を、人の実描画・採点・資料提供を待たずに進めるための計画です。目標は、**体幹の単純化の手順を出典付きで比較し、記憶描画と修正に関する根拠を整理して、未実施の課題仕様へまとめること**です。公開一次資料と保存済み資料を使い、調査・図解・設計・文書点検までを対象にします。

前回の[調査計画](research-plan.md)のA〜D・Q1〜Q6は当時の範囲で完了しています。本計画は追加の作業範囲であり、その完了監査をやり直すものではありません。最新のユーザー指定に従い、人による確認を必要とする実践フェーズを今回の完了条件から外します。

## 対象と除外する作業

ここで除外する「人による確認」は、ユーザー・参加者・専門家などに新たな作業や判断を依頼し、その結果を待つことです。AIによる公開本文・図版・動画の確認や、コード・リンク・出典の点検は実施します。ただし、それを専門家の査読や人による使いやすさの確認とは扱いません。

| 推奨案 | 今回実施する部分 | 今回の対象外 |
| --- | --- | --- |
| 人体の単純化を図で比較する | 原典の手順・基準点・省略・例外を照合し、独自の模式図と比較資料を作る | 人に描いてもらう、図の自然さ・分かりやすさを評定してもらう |
| リクノの未確認部分を精読する | 正規の公開本文・見本・本人解説を探索し、読める範囲を節別に確認する | 購入、貸出、ユーザーへのスキャン・資料提供依頼、著者への問い合わせ |
| 小さな試行で課題と採点を確かめる | 課題仕様、記録項目、評価候補と測定上の問題を文書化する | 実描画、実測、自己・第三者採点、採点一致や実行負担の実測 |
| 観察と記憶描画と修正を検証する | 描画研究・古典・実演解説を調べ、比較できる条件を設計する | 参加者募集、練習介入、保持・転移試験、効果の実証 |

既存の[箱比率実験](../experiments/2026-10-02_torso-ratio-pilot.md)の実施や装置確認を、この計画の前提にしません。実験の条件・閾値は変更せず、新しい案は別の草案として保存します。個人の技能水準・作品・希望日程がなくても進む範囲に限定します。

## 作業順序と依存関係

基本順序は、原典確認 → 比較と図解 → 記憶描画の根拠整理 → 課題仕様 → 総括と点検です。本文・図を取得できない枝は保留へ移し、独立した作業を続けます。以下は開始時に定めた作業と完了条件です。実施結果は末尾の進捗表・照合先を参照してください。

### 原典の手順と図版を確認する

最初に、[Prokoの資料ノート](../references/videos/proko-robo-bean-and-obliques.md)からRobo BeanのLandmarks、Differences、Motion、More about the Twistの図・公開解説へ進みます。計画開始時点のノートでは本文を確認済みで、図の細部は未照合でした。箱の範囲、骨の目印、向き、重なり方と訂正箇所を確認します。

次に[リクノ第1巻](../references/books/rikuno-2015-line-design.md)の出版社・本人の公開資料から、第2章の「いもむし理論」「箱パース理論」「線画裏立体把握」を優先して探索します。理論名だけで適用部位や内容を推定しません。第2巻や他書の全体精読へは広げず、比較の判断を変える公開箇所だけを追加します。

[洞田の資料](../references/artists/toda-kobun-method.md)は確認済みの本文・図を再利用し、比較に必要な基準点や例外に矛盾がある場合だけ該当箇所へ戻ります。古典の構築法は[Bridgman](../references/books/bridgman-1920-constructive-anatomy.md)の主要な量と接合に関係する図版を対象にし、全図版の精読は求めません。

各方法について、次を同じ書式で抽出します。

- 解決したい問題、対象部位、前提となる知識。
- 描く順序と、その順序が本文・図・動画のどこに示されるか。
- 箱や曲面が表す範囲、基準点、残す情報と省く情報。
- 著者が述べる例外・訂正と、当リポジトリが推測する限界の区別。
- 確認した版・頁・節・図、動画なら時刻と音声・字幕の照合範囲。

**完了条件：** 対象ごとに確認結果か取得保留の記録があり、比較へ採用できる手順が明確になっている。本文未取得の固有理論は「未確認」を維持する。リクノの詳細を読めない場合でも、確認できた他の方法による比較は進める。

### 体幹の比較と模式図を作る

[既存の抽象化比較](../research/comparisons/figure-abstraction-and-classical-methods.md)を入口に、手順を確認できた方法を少なくとも2つ比較します。第一候補は洞田式の体幹構築とProkoのRobo Beanです。Beanは丸い量による動きの表現として併記し、リクノ・Bridgmanは確認できた内容だけを追加します。異なる目的の方法を総合点で順位付けしません。

比較対象は、中立姿勢、側屈、胸と腰のねじれを候補とします。各姿勢について、原典から説明できる範囲を確認して採用し、未確認の姿勢は無理に埋めません。本文・図の裏付けがある共通の姿勢を最低1つ扱い、それ以外の不足を明記します。

模式図は編集可能なSVG等で作成し、対応する出典と独自の作図判断を添えます。教材の図版をなぞって転載せず、独自の配置・説明で関係を示します。共通の向きや配置は比較用の仮定として明記し、方法ごとの基準点や箱の意味まで同一にしません。

**点検すること：** 図のラベルと本文の対応、投影・前後関係の内部整合、出典との対応、文字の欠けや重なり。座標計算で確認できるのは幾何学的な整合だけです。模式図を実際の人体の正解画像や学習効果の証拠として使いません。新たな解剖学上の断定が必要なら現代の一次的な教材・学術資料で別途照合し、解決できない箇所は描き込まない方針とします。

**完了条件：** 2方法以上について共通の姿勢を比較し、手順・図・基準点・省略・限界を追える。図の表示と内容をAIが確認できた範囲、確認できなかった範囲を記録する。単なる作図案を完成図として数えない。

### 記憶描画と修正の根拠を調べる

問いは「参照を見ながら描く場合と、参照を閉じて描いた後に照合する場合で、何が学習され、何を測れば違いが分かるか」です。次の3種類を分けます。

1. 同じ見え方を記憶から再現する。
2. 参照条件をそろえて、時間が経っても技能が保たれるか調べる。
3. 別の題材や未提示の角度へ構造を適用する。

[学習原理の整理](../research/learning-science/learning-and-practice-evidence.md)と既存の描画研究ノートを起点に、直接関係する原著の方法・結果を優先します。たとえばNewell、Liu、Albaret & Thonの未確認箇所は、今回の条件比較を変える場合に絞って再取得します。一般記憶・運動技能の研究は間接資料として扱います。

追加検索では `drawing from memory feedback learning retention`、`observational drawing recall transfer`、`記憶描画 模写 フィードバック 学習` 等を出発点とし、比較条件・保持・転移・効果なしの結果と、引用元・後続研究を辿ります。これは予定検索語であり、実施記録には実際に使った検索式・日付・範囲だけを記載します。

古典は確認済みの[レオナルド](../references/books/leonardo-memory-and-functional-anatomy.md)と[Speed](../references/books/speed-1913-visual-memory.md)の手順を再利用します。Lecoqの原典は既存の取得失敗を踏まえ、新しい正規公開経路が見つかった場合だけ補足します。作家については、[Kim Jung Giの資料](../references/artists/kim-jung-gi-learning-interviews.md)にある公開インタビュー・実演解説を優先し、観察・記憶・修正の具体的操作を確認します。寺田克也・吉成曜の追加取材は、既存の発言の食い違いや具体的手順を解消する場合に限定します。

抽出項目は、対象者、課題、参照の条件、練習・閲覧・修正時間、比較条件、評価時点、実際に描いたものの評価かどうか、結果と限界です。作家の回想や古典の教えは、効果研究と別欄に置きます。字幕だけなら音声確認済みとは記さず、非公式翻訳だけの発言は採用を保留します。

**完了条件：** 観察模写・記憶再生・別角度への構築を区別した根拠表があり、採用できる研究と取得保留の影響が分かる。比較研究を得られなかった場合も実際の探索範囲と設計上の不足を残す。普遍的な必要時間や方法の優位を無理に決めない。

### 実施前の課題仕様を作る

前の2作業の成果を使い、観察構築・記憶再生・未提示角度への構築について、課題の目的、入力、手順、成果物、評価候補を定義します。実験開始や参加者の募集は行いません。

| 課題候補 | 仕様に含めること | 今回判定しないこと |
| --- | --- | --- |
| 参照ありの構築 | 参照と手順書の利用条件、基準点、位置・向きの評価候補 | 人が手順を理解できるか、実測の採点一致 |
| 参照を閉じた再生 | 観察・描画・照合の区切り、観察模写との条件差、記録項目 | 記憶練習の優位、必要な練習量 |
| 未提示角度への構築 | 既知の立体モデルなど正解を定義できる対象、練習角度と評価角度の分離 | 任意の写真1枚から見えない形を唯一の正解として決めること、人体全般への転移 |

1枚の写真から裏側の形を推定する課題では、正解が一意に決まらない場合があります。幾何学モデルを使う案は、幾何学モデル上の構築として範囲を限定します。人体らしさ・演技・魅力など、今回人の評価が必要な項目は主評価に入れません。

時間、反復数、改善閾値は、未実測の推奨量として固定しません。将来の試行で決める事項として明示し、文書を「実施可能性確認済み」としないことを条件に、仕様草案として完成させます。模擬座標を使う場合は計算例と明記し、実データの保存先へ入れません。

**完了条件：** 3課題の違いを説明でき、手順と評価候補の対応がある。机上で確認できることと、人による後続試行で確認する事項が分離されている。後者は今回の未完了タスクには数えない。

### 総括と資料の点検を行う

今回分かったことを、読者が次の4点を追える形でまとめます。

- 単純化の各方法が残す情報と、その違い。
- 記憶・観察・別角度への構築について直接分かることと仮説。
- 原典の再確認によって、以前の説明を修正した箇所。
- 未確認のため採用しなかった手順と、結論への影響。

[資料方針](evidence-policy.md)と[運用ルール](conventions.md)に従って、根拠の種類・確認範囲・出典・引用・索引・内部リンク・数値を点検します。新規図版も点検し、実施した検査と未検査を区別します。`ready` は資料の整備状態であり、効果の実証ではありません。メソッドを `stable` へ移しません。

## 取得できない資料の扱い

原典が取得できなければ、出版社・著者・機関リポジトリ・図書館の公開版など、異なる正規経路を確認します。原則として新しい代替経路を2つまで確認し、有効な経路がなければその枝を保留にします。既に失敗した経路は、新しい情報がない限り繰り返しません。この回数は調査を進めるための運用上の目安で、網羅性の基準ではありません。

保留には、対象箇所、試した経路、取得できない理由、主張への影響、再開条件を記録します。ユーザーへの購入・アップロード・確認依頼を、この計画を続けるための前提にしません。アクセス制限を回避せず、独立した作業へ移ります。

リクノの固有理論を確認できなくても、公開資料で確認できた考え方は残します。一方、図解比較に必要な2方法の手順・図を確認できない場合は、その成果物を完了扱いにしません。記憶描画の調査や総括を進めたうえで、達成できなかった条件を明示します。保留欄を埋めるだけで必須条件を達成扱いにしない方針です。
