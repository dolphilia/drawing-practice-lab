# 評価・検証ガイド

目的は、自分の目標に対してどの練習がどの条件で役立ったかを判断することです。日々は短い日誌で十分です。メソッドを採用する際には、以下の条件を明確にします。

## 始める前に決めること

1. **問いを1つに絞る**。「絵が上達する」ではなく「人体の主要な比率を捉える誤差が減る」など。
2. **対象と条件を残す**。現在の経験、画材・ソフト、キャンバス寸法、制限時間、題材、資料参照・補助機能の有無を記録する。
3. **比較を決める**。練習前後の比較か、通常練習との比較かを明記する。方法同士を比べる場合は総練習時間をそろえる。
4. **評価を先に固定する**。観点は1〜3個に絞り、尺度・採点者・改善とみなす基準を決める。好き嫌いや作風の評価と、技能の評価を分ける。
5. **再評価の予定を決める**。直後に加え、時間を置いた同条件の課題と、未練習の題材での課題を計画する。

## 評価表の作り方

数値で測れる場合は測定方法と単位を記載します。目視の場合は「よい・悪い」だけでなく、各段階で何が観察できるかを言葉にします。評価基準はドリルまたは技能文書に置き、実験では使用した版・基準を固定します。

次は**記入方法の例**であり、標準化された尺度でも実測結果でもありません。

| 観点の例 | 測り方の例 | 注意点 |
| --- | --- | --- |
| 比率 | 指定した2つの長さの比を測り、参照との差の絶対値を記録する | 測る箇所と参照画像を固定する |
| 明暗の整理 | 0＝明部と暗部が混在、1＝分離するが例外が多い、2＝指定した主要面で分離できる | 境界例を自作の見本で残す |
| 続けやすさ | 実施回数 / 予定回数と負担のコメント | 技能の改善とは別に記録する |

採点は、可能なら制作日や練習条件を隠して順番を混ぜて行います。同じ基準で再採点するか、他者の評価も得ると、自己評価の偏りを点検できます。

## 実施後に確認すること

- **直後の出来栄え**：同条件でどう変わったか。
- **保持**：練習から時間を置いてもできるか。例えば1週間後。ただし間隔は課題に応じて事前に決め、間の練習も記録する。
- **転移**：未練習の題材・角度・制作課題で使えるか。題材の難易度差が残ることにも注意する。
- **負担**：時間、集中、楽しさ、継続のしやすさはどうだったか。

一度だけの成功作ではなく、複数の試行と失敗例も残します。欠測・中断・計画変更を記録し、未実施を0点として扱わないでください。

練習前後の差だけでは、そのメソッドが原因だと断定できません。題材への慣れ、ほかの練習、採点のぶれ、当日の調子なども考察します。一人で A → B の順に試すと、A で身についた技能が B に持ち越されるため、後の方法ほど有利になる可能性があります。

## stable にするための基準

以下は**このリポジトリで採用する運用基準**です。科学的な証明や、研究で定まった必要試行数を意味しません。

- [ ] 対象者・目標技能・適用条件・向かない条件が書かれている
- [ ] 手順、使用した版、評価基準、結果にアクセスできる
- [ ] 事前に決めた改善基準を満たし、別日にも同方向の結果を確認した
- [ ] 保持と転移を確認した。未確認の範囲は採用対象から外し、その理由を記載した
- [ ] 失敗・悪化・負担・ほかの説明を検討した
- [ ] 実験へのリンク、採用日、判断理由、再検証する条件を残した

肯定的な結果と否定的な結果が混在する場合は条件を絞るか、`testing` を継続します。効果なし・判断不能でも実験は `done` にできます。

## 設計の根拠と適用範囲

練習中の遂行と保持・転移を区別する考え方は [Soderstrom & Bjork のレビュー](../references/articles/soderstrom-bjork-2015-learning-versus-performance.md)を参考にしています。目標とフィードバック条件を残す設計には [Newell ほかの描画課題研究](../references/articles/newell-1990-drawing-feedback.md)も参考にしました。具体的な記録項目と採用基準は、このリポジトリのための設計判断です。これらの文献が、ここで開発するイラスト練習法の効果を直接実証しているわけではありません。
