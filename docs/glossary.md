# 用語集

| 用語 | 読み・英語 | このリポジトリでの意味 |
| --- | --- | --- |
| アタリ | — | 本描きの前に形や位置を大まかに示す下描きの線 |
| パース | perspective | 遠近法。ここでは主に消失点を使う線遠近法を指す |
| 明度 | value | 色の明るさの度合い |
| スキル | skill | 観察できる到達状態を定義した、身につけたい技能 |
| メソッド | method | 練習の原理・方針・適用条件をまとめたもの |
| ドリル | exercise | 時間・題材・手順・評価を具体化した練習単位 |
| プログラム | program | ドリルを目的に沿って組み合わせた練習計画 |
| ベースライン | baseline | 練習前に記録する比較の基準 |
| ルーブリック | rubric | 観点ごとに、各評価段階で観察できる状態を定めた基準表 |
| 保持 | retention | 時間を置いても、練習した技能を使えること |
| 転移 | transfer | 未練習の題材や異なる制作場面で技能を使えること |
| フィードバック | feedback | 結果と目標の差を知り、次の試行の修正に使う情報 |
| 仮説 | hypothesis | 検証前の予測。観察結果と区別して記録する |
| stable | — | 明記した対象・条件内で採用したメソッドの状態。普遍的な効果の証明ではない |
| 量・量塊 | mass | 描画上、一つのまとまりとして扱う立体。質量の測定値ではない |
| 断面線 | cross-contour / section line | 立体を横切る面や回り込みを示す説明用の線。外側の輪郭線と区別する |
| ランドマーク・目印 | landmark | 対応付ける位置の手掛かり。骨の目印、構築用の点、幾何学モデルの固定点は同一ではない |
| 平行投影 | orthographic projection | 奥行きによる縮小を行わず、カメラの右・上方向へ座標を写す投影 |
| 対応点 | correspondence | 参照と入力で同じ対象位置を表す点。ID等で対応を定義する |
| 位置合わせ | registration / alignment | 移動・回転・尺度等を調整して比較する処理。調整した種類の誤差を隠す場合がある |
| 合成データ | synthetic data | 定義した規則・モデルから作った計算用のデータ。参加者が描いた実測結果とは別に保存する |
