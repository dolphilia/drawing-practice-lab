## 1. 目的と到達点

イラストの練習方法を、出典を追える知見と再現可能な手順から開発できる状態にします。キャラクターイラストを最初の重点領域とし、観察、空間構築、構図、配色などにも使える知見を蓄積します。

当面の到達点は、**一つの狭い描画技能について、練習候補・根拠の限界・評価方法・評価時期を説明でき、探索的な実験計画へ渡せること**です。資料数の増加や、人気教材の網羅だけを成果にしません。

この計画はリポジトリ運用上の設計です。研究で有効性が確認された調査日程ではありません。資料収集と実際の練習・効果検証は分けて管理します。

利用可能な調査時間が未設定のため、固定の締切は置かず、成果物と完了条件で進めます。1回の調査は一つの問いに絞り、検索・選別・精読・統合を一巡させます。終了時に実作業時間と残件を記録し、次回の範囲を調整します。

| 段階 | 実施内容 | 完了条件・次段階への引き渡し |
| --- | --- | --- |
| A：既存資料の点検 | Q1・Q2に使う原著と測定資料を優先して読み直す。訂正・人数・評価対象・数値の出典を確認 | 下の初回作業表の各項目に、確認結果か保留理由・代替経路がある。既存分析に修正を反映 |
| B：評価と学習原理 | Q1〜Q3を問い別に検索。直後・保持・転移と、実時間・期間・頻度を抽出 | 狭い技能の評価候補を少なくとも一つ説明できる。評価時期の根拠と運用判断が分かれ、判断不能な点が明記される |
| C：教材とキャラ絵 | Q4・Q5。洞田式の全体確認を優先し、同じ技能を狙う他の方法と比較。薄い技能領域を補う | 各重点技能について教材・評価研究の探索状況が追える。少なくとも一つの候補で手順・前提・評価課題を記述できる |

これらの語を一度にすべて結合しません。まず課題と成果で検索し、必要に応じて対象者や研究設計を加えます。たとえば表情を「認識する」研究が見つかっても、「描けるようになる」研究とは別に分類します。

### 1問ごとの探索順序

1. 既存ノートと重複しないか確認し、対象技能・比較条件・成果・必要な判断を一文にする。
2. 日英の検索と関連する学術索引で概観を探す。基本文献を落とさないため、最初から古い研究を除かない。
3. 重要資料の引用文献を遡り、被引用文献を辿って追試・批判・訂正・更新を探す。補助として2020年以降の更新検索も行い、範囲を記録する。
4. 肯定的な語だけでなく、null、no effect、replication、limitations、効果なし、追試、転移しない等も試す。該当語の有無だけで採否を決めない。
5. 主要主張の原著・公式教材へ戻り、条件と結果を確認する。別サイトの同一要旨を追加の裏付けにしない。

検索ごとに日付、検索先、実際の検索式、言語・年の範囲、並び順、確認した件数または範囲を残します。検索上位だけ、時間制限で途中まで、といった場合はその範囲を明示します。ヒット総数を実際に確認した件数と混同しません。

## 6. 候補の選別と信頼性の評価

### 採用・保留・除外

| 判定 | 基準・扱い |
| --- | --- |
| 採用 | 問いに関係し、出典が追え、何を根拠にした主張か区別できる。弱い根拠でも教材や仮説として有用なら分類して採用 |
| 保留 | 本文・図版を入手できない、対象や条件が分からない、同一研究か未確定。理由と次の確認経路を残す |
| 除外 | 問いに関係しない、出典を特定できない、内容のない転載など。理由を候補表に残す |
| 重複 | 同じ論文・教材の別掲載先。既存ノートに統合し、対応先を残す |

広告を含む教材や査読前論文も、それだけで一律に除外しません。宣伝上の主張、利益相反、査読状況を確認し、根拠の種類と限界を記します。否定的・有意差なしの結果も同じ基準で選びます。

本文が入手できない場合は出版社、著者版、所属機関の公開版を確認します。利用できる経路で確認できなければ保留にし、要旨から未記載の数字を補いません。未入手資料の一覧を残し、必要性の高いものから再検討します。

### 研究と教材で確認項目を分ける

- **研究**：割付・比較条件、参加者の経験と人数、脱落、実施量、評価者の盲検化、尺度の妥当性・信頼性、効果の大きさと不確実性、追試、登録・公開データの有無を確認する。存在だけで良し悪しを自動判定しない。
- **レビュー**：検索・選別方法、元研究の質、異質性、研究の重複、更新時期を確認する。レビューとそこに含まれる原著を独立した支持研究として二重に数えない。
- **教材**：対象技能・前提・手順・指定量・修正の仕方、成功例以外の情報、独立評価の有無を確認する。著者の技量と指導法の効果を別に扱う。
- **隣接分野**：元課題と目標の描画で共通する要素、異なる要素、直接の転移テストの有無を確認する。

最終判断は主張単位で「何が支持されるか・なぜ・何が未確認か」を文章で残します。根拠の種類を一つの点数に変換して、人気と研究の質を混ぜたランキングは作りません。

## 7. 抽出する情報と保存先

個別資料は [資料テンプレート](../templates/reference.md)、一巡の検索と選別は [収集記録テンプレート](../templates/collection.md)を使います。収集記録は `research/topics/YYYY-MM-DD_collection-<theme>.md` に保存します。事実の本体は資料ノートに置き、分析や計画へ同じ長文を複製しません。

| 情報 | 必須の区別・記録 | 保存先 |
| --- | --- | --- |
| 書誌と所在 | DOI・版・著者・確認日・ページ／節／タイムスタンプ | `references/` |
| 研究の単位 | 募集人数／解析人数、同じ標本を使った別論文、レビューとの包含関係 | 資料ノートと収集記録 |
| 練習条件 | 実際に描く分数／説明・視聴／評価、1回の量／頻度／総期間、予定量／実施量 | 資料ノート、評価時期の分析 |
| 評価 | 直後／保持／転移、終了後の間隔、資料参照・補助、同一題材／未見題材 | 資料ノート、評価候補表 |
| 結果と限界 | 効果・不確実性、否定的結果、交絡、未確認箇所 | 資料ノート |
| メソッドの手順 | 狙う技能、前提、材料、工程、修正、難易度調整、原典と独自案の境界 | 資料ノート、メソッド比較 |
| 横断的な判断 | 一致・相違、適用範囲、仮説、判断を変える証拠 | `research/` |

未確認、未報告、対象外を区別します。「未報告」は該当箇所を調べた場合にだけ使います。定量値を転記するときは単位と分母を確認し、訂正した値は参照している分析にも反映します。

### 必要時間の調査で守ること

研究が「その量で測った」だけなのか、複数の量を比較して用量との関係を調べたのかを分けます。最短の研究を、必要最小時間の証拠にはしません。経験や課題が違う研究の日数を単純平均せず、条件別に比較します。

評価日程へ引き渡すときは、研究で使われた間隔、目標とする保持期間、測定のぶれ、実行可能な日程を並べ、採用理由を説明します。根拠が足りなければ [既存の日程例](../research/learning-science/practice-dose-and-evaluation-timing.md)のように「探索のための運用案」と明記します。

## 9. 調査を区切る条件と見直し

一つの問いについて、予定した検索経路、引用・被引用の追跡、反証の探索を行い、候補の採否と未取得資料を記録したら、その回を区切ります。時間上限に達した場合は「範囲限定の途中結果」として残します。新しい条件や結論が得られなくなったことは区切りの材料ですが、網羅性の証明にはしません。

調査記録の終わりには、次のどれかを記載します。

- **追加調査**：判断を変える具体的な不足があり、次の検索・精読先が決まっている。
- **実験候補へ**：手順と評価を定められ、残る不確実性を小規模な試行で調べられる。
- **保留**：取得・測定・適用範囲に問題があり、再開条件を記録している。

各段階の終了時に計画を見直します。新しいレビュー・訂正・反証、実験での予想外の結果、目標技能の変更があれば関連する問いを再開します。定期的な再検索を実施する場合は別途日程を設定し、この計画だけで自動実行を開始しません。

## 10. 成果の確認とメソッド開発への移行

進捗は新規件数に加え、次を確認します。分母が変わるため、対象に選んだ資料・技能の一覧も残します。

- 重点資料のうち、方法・結果まで確認できたものと、保留理由が付いたものの割合
- 練習量・評価時期・評価指標を抽出できた研究と、抽出できない理由
- 技能表のうち、教材と評価研究の両方を探索した領域
- 独立した裏付け、反証、根拠の不足によって結論を修正した箇所
- 手順・評価・限界を説明できる実験候補

件数や割合を達成するために弱い資料で欄を埋めることはしません。一人で行う調査では独立した二重選別をしたとは記さず、重要な数値と採否を最後に読み直します。

最初の調査サイクルを完了するときの確認項目は次のとおりです。

- [x] Q1〜Q6に、調査済み・未着手・保留の範囲と次の判断がある
- [x] 重点的に使う数値・手順の原典確認が済むか、使用を保留している
- [x] 評価方法と時間・期間の根拠、運用上の仮定を区別している
- [x] 洞田式を含む重点教材の手順と適用限界を追える
- [x] 新規・更新資料を索引へ反映し、リンク・分類・重複を点検した
- [x] 少なくとも一つの候補で、検証可能な問いを作った。または作れない理由と再開条件を明記した

実験へ進める候補は `methods/drafts/` と [実験テンプレート](../templates/experiment.md)へ引き渡します。評価指標、意味のある改善幅、比較条件、総時間、保持・転移、打ち切り条件を開始前に定めます。調査が終わっただけで `stable` にはせず、採用は [評価・検証ガイド](evaluation.md)に従います。
