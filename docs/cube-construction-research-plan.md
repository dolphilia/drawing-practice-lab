# 立方体を手作業で透視作図する方法の研究計画

作成日：2026-10-02。現在地は**第1〜6段階を完了し、人が使う手順の候補を整備した段階**である。第7段階の人による作図・時間・精度・学習の確認は未実施。

## 目指す成果

方眼紙、コンパス、分度器、一般的な三角定規2種、直線定規、鉛筆、消しゴム、一般的な卓上計算機を使い、**指定した立方体を、さまざまな方向・距離・画面条件で描く方法**を作る。立方体を描けることを前提にした人体のアタリの研究から一段さかのぼり、その立方体自体の作図を対象にする。

成果は一つの万能なコツでなくてもよい。正確な基準法、少ない操作で描く方法、条件付きの近似法と、その使い分けがそろえば目的に合う。各方法には入力、手順、必要な紙面、計算、適用範囲、誤差、失敗時の戻り方を付ける。

成果を使うには[手順書](cube-construction-manual.md)、判断と要件の照合には[総括と完了監査](../research/topics/cube-construction-completion-summary.md)を参照する。以下の研究順序と完了条件は計画時の基準として保持する。

計画時の資料は[初期調査と可能性の整理](../research/topics/cube-construction-feasibility.md)。原典の確認範囲は[収集記録](../research/topics/2026-10-02_collection-cube-construction.md)、今回の検算は[数式検算の記録](../assets/cube-projection-research/README.md)に残した。

## 最初の判断

幾何学的に作図する道筋はある。未解決なのは、任意の向きの設定を含めて、どの方法が実際に扱いやすく、どこまで簡略化できるかである。

最優先は、**正確な中心投影を、紙上の作図と四則演算の二通りで再現すること**。これを基準に、消失点・測点の方法、補助尺度、近似を比較する。入力をコンピューターがすべて準備してしまうと、難しい前処理を隠すことになるため、人が入力を作る工程も方法に含める。

| 比較候補 | 優先度 | 最初に解く問題 |
| --- | --- | --- |
| 視線と画面の交点を紙上で取る | 最優先 | 相似三角形・正投影図から8点を得る標準手順 |
| 3本の半辺ベクトルと頂点別の縮尺計算 | 最優先 | 向きを設定し、四則演算の表へ落とす手順 |
| 消失点と測点で辺長を移す | 次 | 一点・二点から三点へ進め、紙外の点を扱う |
| 自作尺度と比例作図 | 次 | 初回準備と繰り返しの節約を分けて比較する |
| 奥行き補正の近似 | 基準法の後 | mm単位の許容誤差と、正確な方法へ戻す条件 |

現段階の順位は研究の順序であり、描きやすさや優位性の順位ではない。

## 道具と入力の約束

### 人が使う道具

ユーザー指定の道具だけで実行できることを必須にする。三角定規は45度のものと30度・60度のものを想定する。計算機は四則演算だけを共通条件とし、平方根・三角関数・プログラム・メモリは任意の便利機能としても必須にしない。

角度の成分は、円・垂線・方眼から読み取る手順を候補にする。平方根が必要なら直角三角形の斜辺を作図して長さを取る方法を検討する。自作の表や補助尺度も、その場で指定道具から作れることを条件にし、作成時間・紙面を費用に含める。印刷済みの表、透明シート、追加の特殊定規、スマートフォンは必須にしない。

### 研究側が使う道具

研究側はプログラムで正解座標、作図シミュレーション、誤差、図解を作ってよい。ただし、その出力を人に渡すだけで「人が任意の条件を作図できた」と判定しない。人の手順から、角度設定・座標生成・尺度作成を隠さない。

### 比較のために固定する入力

| 入力 | 意味と初期方針 |
| --- | --- |
| 立方体の辺長 | 3方向の実長が同じ。図の上の辺長が同じという意味ではない |
| 立方体の位置と姿勢 | 中心位置と3本の直交軸、または順序を定めた回転で指定 |
| 視点の位置 | 立方体との距離と左右上下の位置関係を決める |
| 見る向きと画面の上方向 | 画面の法線と回転を決める。真上・真下でも上方向を明示 |
| 画面距離f | 視点から画面までの垂直距離。対象距離とは区別 |
| 紙上の原点と倍率 | 全方法で共通にし、結果を見た後で自由に合わせ直さない |
| 用紙と許容範囲 | 初期案はA4、実際の作図範囲180×250mm。追加紙や紙外操作は別途計上 |

用紙寸法は比較用の設計案であり、ユーザーの道具条件を狭める最終仕様ではない。補助図を別紙に描く場合は枚数と最大広がりを記録する。紙外の消失点が必要な方法を、追加の机や長い定規があるものとして扱わない。

入口は「辺長・姿勢・距離から描く」を先に完成させる。後から「見せたい面の割合や傾きから、対応する条件を選ぶ」入口を加える。後者は正解が一意に定まらないことがあるため、入力の不足を明示する。

## 作図対象と境界条件

基本は平面上への単眼中心投影。画面に平行な辺の組が二つ・一つ・ゼロの場合を、一点・二点・三点透視の条件として整理する。立方体の見える面数と消失点の数を同一視しない。平行投影・等角図は補助図と比較用に残す。

段階的に次を扱う。

1. 正面に平行な面を持つ立方体。
2. 左右に回した立方体と、目線より上・下にある立方体。
3. 俯瞰・あおり、画面内の回転、傾いた立方体。
4. 真上・真下、ほぼ正面、辺がほぼ画面に平行な場合。
5. 視線の中心から外れた位置、近距離、強い短縮。

標準課題は全頂点のZが正である立方体に限定する。Z=0では投影が有限にならない。視点をまたぐ立方体は、辺の切断・クリッピングを要する別課題として判定し、通常の8点作図へ無理に押し込まない。有限でも用紙を大きく外れる場合は、共通倍率を変更するか適用外とする。

## 継続作業の順序

一回の作業で一つの問いを閉じ、結果と次の入口を残す。期間の約束よりも成果物と完了条件で管理する。以下の保存先は、未作成のものについては予定名であり、作成時にリンクを付ける。

### 第1段階　共通の入力と正解を定義する

**問い：** 同じ「角度・視点」と言ったとき、全方法が同じ立方体と画面を表しているか。

座標の正方向、単位、頂点番号、12辺、回転順序、画面条件を固定する。ワールド座標から視点座標へ移す説明と、最初から視点座標で指定する説明を作る。ユーザーは毎回行列を書く必要がないようにする一方、研究側では両者の対応を残す。

独立した基準として、視線と画面の交差、および座標変換後の奥行き除算を照合する。同じ関数を呼び出す二つの実装を独立検査とは数えない。単純な有理数例、既知の平行条件、対称性も使う。

**完了条件：** 下記の基本24条件・境界12条件に期待動作があり、有限な正解と適用外を機械的に区別できる。向き・焦点距離・表示倍率を混同する入力は検出される。保存予定は `assets/cube-projection-research/cases.json`、同所の基準投影コード、`research/topics/cube-projection-input-spec.md`。

### 第2段階　正確な二つの基準手順を作る

**問い：** 投影図を紙上で作る方法と、計算機で座標を出す方法を、同じ入力から最後まで実行できるか。

まず一点・二点の簡単な条件から始める。視線を使う方法は補助図の配置・縮尺・高さの移し方を決める。計算法は、姿勢の設定、3本の半辺ベクトル、8頂点の符号表、頂点ごとの縮尺、点を結ぶ順序を一続きの手順にする。原典の図は精査してから参照し、説明用の図は独自に作成する。

角度成分を読み取る円の半径、目盛り、符号の付け方、途中値の保存桁数を仕様にする。特定の三角比がすでに与えられた例だけで終えない。三角定規2枚を用いた平行移動・垂線の操作も説明に含める。

**完了条件：** 少なくとも一点・二点・一般の三点透視を各1条件、入力から8頂点・12辺まで追える作業例がある。理想的な作図操作の計算結果が基準と一致し、丸めを入れた結果を別に報告する。使用道具の追加や暗黙の正解座標を必要としない。保存予定は `methods/drafts/cube-ray-construction.md`、`methods/drafts/cube-depth-scale.md` と対応する図解・作業表。状態は `draft`。

### 第3段階　既存の測点法と紙外の点の扱いを比較する

**問い：** 消失点・測点による作図は、基準手順よりどの場面で操作を減らせるか。

Storey・Ruskinの確認箇所を図と照合し、一点・二点の実長の取り方を再構成する。三点透視はIllinois大学の構成を入口に追加調査する。図を取得できない資料は基準法から外し、他の公開資料や独立導出で進める。

紙外の点は、補助図の縮小、対応する基線の縮小、局所的な比例移送を候補にする。縮めた消失点だけを元の図に接続してよいとは仮定しない。縮小が座標精度へ与える影響も測る。

石川論考は画面条件と投影の定義を先に照合する。単一の中心投影に対応しない、または対応を確定できない場合は、補助的な作図案として記録し、正解を作る役割を与えない。

**完了条件：** 採用候補ごとに入力条件・参照した図と節・同一条件の再現・紙外対応・適用外がそろう。少なくとも一つの測点を使う作図を基準と比較する。三点透視が未解決なら範囲を二点までと明示し、全視点対応を称さない。保存予定は `research/comparisons/cube-construction-methods.md`。

### 第4段階　手間を減らす案と近似を選別する

**問い：** 精度を保つ工夫と、誤差を許す工夫のどちらが実用的か。

先に計算結果の再利用、対称頂点、画面内回転、共通の奥行き、比例作図など、投影モデルを変えない工夫を試す。その後、奥行き別の自作尺度、表の補間、一次・二次補正、角度の量子化を比較する。

一度に変える工夫は一つとし、組合せは各誤差を確認した後に試す。正確な割算との比較で操作が減らなければ、近似案は採用しなくてよい。作図の理由を理解しやすい等の利点を主張する場合は、人による確認待ちとする。

**完了条件：** 残す案に誤差上限または条件別の誤差表、事前に判断できる適用条件、条件外で戻る方法がある。少なくとも一つの「正確な省力化案」と一つの「近似案」を評価し、採用または見送りの理由を残す。保存予定は `research/comparisons/cube-construction-accuracy-and-effort.md`。

### 第5段階　道具の読み取り誤差に対する強さを調べる

**問い：** 理想的な計算ではなく、少しずれた線・角度・目盛りでも使えるか。

分度器の設定、長さの読み取り、交点、座標の丸めを別々に変える。初期の仮想条件は長さ±0.25・0.5・1mm、角度±0.5・1・2度。これらは人の誤差の実測値ではなく、感度を調べる試験条件である。誤差ゼロも含める。

独立したばらつきだけでなく、同じ尺度が全体にずれる、同じ角度が全頂点に影響する、といった共通の誤差も入れる。ほぼ平行な線の交点、紙外の消失点、近い頂点を重点確認する。

**完了条件：** 設計24条件と境界条件について、どの操作が誤差を増幅するか分かる。最終出力でだけ誤差を足す模擬検査は、作図工程の感度検査と区別する。ソフトウェアで確認できない操作は保留として明記する。保存予定は同じ素材ディレクトリの検査コードと `research/topics/cube-construction-sensitivity.md`。

### 第6段階　人が使う手順書へまとめる

**問い：** 数式を理解していない人も、入力から完成まで迷わず進められる説明になっているか。

入口は一点・二点・三点のラベルだけに頼らず、正面、斜め、俯瞰・あおり、傾き、近距離の例で案内する。各手順は「今決める量」「行う操作」「その時点の確認」を対にする。用語集、記入済みの例、空の作業表、失敗診断、方法の選択表を用意する。

**完了条件：** 道具・前提・全工程・適用外が記載され、図と値が一致する。研究側の文書点検を終えた時点では「人が容易に使える」と判定せず、手順書の候補として保存する。保存予定は `docs/cube-construction-manual.md` と `exercises/construction/` 内の候補ドリル。

### 第7段階　必要なら人による作図で確かめる

**問い：** 紙と指定道具を使った実際の結果は、設計どおりか。

ここから初めて人の実描画を必要とする。第1〜6段階は、人の承認・実描画・採点・資料提供を待たずに進められる。今回の依頼では人の参加や実験開始を要求せず、実施計画を準備するところまでを将来の作業に含める。

人の確認は四つに分ける。

| 確認 | 記録すること | 結論の範囲 |
| --- | --- | --- |
| 手順の実施可能性 | 迷い、質問、使えない操作、消し直し、完遂 | まず1人でも設計上の問題を発見できる |
| 作図の精度と所要時間 | 初回準備、繰り返し1個、誤入力、座標のずれ | 試した人と条件の結果 |
| 方法の比較 | 共通入力、順序の交代、難易度、時間と精度 | 参加者数・反復・順序効果を含めて設計する |
| 身につくか | 後日の再実施、未提示角度、補助表なしの課題 | 作図できたことと学習・転移を分ける |

作図自体は指定道具に限定する。時間測定や座標のデジタル化は研究者側で行い、作図者に追加機器を必須としない。作品をデータ化する手段がなければ、紙上の採寸で可能な範囲を記録し、架空の座標・所要時間を補わない。

参加者数・時間・必要枚数は、手順が完成する前に固定しない。既存の箱比率計画の310分・67枚は別課題なので転用しない。

## 比較用の条件を事前にそろえる

### 基本24条件

確定した比較条件は、次の6姿勢×2距離×2位置＝24条件。立方体の辺長をaとする。第1段階で固定Y→X→Zの順序を定め、上面を見せるβは負となるため初期候補の符号を修正した。[入力仕様](../research/topics/cube-projection-input-spec.md)に変更理由を残した。

| 姿勢 | 確定した回転角 | 主に確かめること |
| --- | --- | --- |
| 正面 | 0度・0度・0度 | 一点透視、対称性 |
| 左右の回転 | 30度・0度・0度 | 二点透視 |
| 斜め上 | 45度・−20度・0度 | 三点透視 |
| あおりと傾き | 65度・35度・15度 | 符号と画面内回転 |
| 強い俯瞰 | 15度・−70度・30度 | 大きな短縮 |
| 真上または対応する極位置 | 0度・−90度・0度 | 上方向の定義、退化の扱い |

距離は中心奥行きD=2a・4a。中心位置は(Xc,Yc)=(0,0)と(0.3D,−0.2D)。紙上のfと倍率は、同一条件の方法間で固定する。対象をすべて同じ完成幅にする比較を追加する場合も、その倍率を正解側で先に決めて全方法へ適用する。

この24条件は網羅証明ではない。一般性は幾何学的導出で説明し、数値検査は誤りを見つける役割を持つ。

### 境界12条件

基本条件とは別に、次の12例を固定する。

1. 回転0.1度で消失点が非常に遠い。
2. 回転89.9度で見える面が非常に薄い。
3. 真下を見る設定。
4. 画面内で90度回した設定。
5. 同じ立方体で画面距離を半分にした設定。
6. 中心距離20aで収束が弱い設定。
7. 最も近い頂点のZが0.1aになる設定。
8. 最も近い頂点のZが0.01aになる設定。
9. 一つの頂点のZが0になる設定。
10. 一部の頂点のZが負になる設定。
11. 有限だが用紙外へ大きくはみ出す設定。
12. 補助図の作図範囲をA4に制限した設定。

条件9・10は通常手順が正しく拒否・分岐するかの検査で、完成図を必ず出す課題ではない。条件11・12は用紙制約の試験。厳しい条件を無告知で除外して、成功率を高く見せない。

## 正しさと手間の評価

### 数学的な正しさ

- 入力の3軸が直交し、辺長が等しいこと。
- 同じ入力の8頂点が基準投影と一致すること。
- 12辺の接続と、必要に応じた可視辺・隠れ辺の区別。
- 同方向の辺の収束、面の対角線などの内部整合。
- 平行・無限遠・視点面をまたぐ条件の適切な分岐。

収束しているだけでは、指定された辺長・位置・姿勢の立方体であることを保証しない。主評価は基準の8頂点との対応にする。消失点が遠い場合は交点位置の差だけに頼らず、画像内での辺の方向・基準線からのずれを見る。

### 紙上の誤差

同じ原点・倍率のまま、各頂点のmm誤差、最大値、二乗平均平方根を報告する。紙の外に出た点も記録する。描画後に移動・回転・拡大して合わせた値は補助指標にし、その合わせ込みで何の誤差を消したかを書く。

初期の選別は最大誤差0.5・1・2mmの三段階で比較する。中心的な比較値を1mmとする案を第1段階で固定するが、これは研究の設計値であり、知覚上の許容限界や道具の実測精度ではない。図の大きさも併記する。幾何学計算の誤差、角度・長さの読み取り、点の配置、線引きは分けて報告する。

### 手間と紙面

| 項目 | 数えるもの |
| --- | --- |
| 前処理 | 角度成分、座標、補助図、尺度・表の作成 |
| 計算 | 四則演算の種類と回数、保持する途中値、桁数 |
| 作図 | 点の配置、直線、円弧、平行・垂線、長さの移し替え |
| 負担の要因 | 転記、符号の切替、分岐、図の混雑、紙外の操作 |
| 空間 | 用紙枚数、補助図の最大寸法、最長の必要直線 |
| 繰り返し | 初回1個と、同じ視点で複数個を描く場合の違い |

異なる操作に根拠のない時間の重みを付けて「最速」と決めない。人の時間測定までは操作数と誤差の両方を示し、片方を良くする代わりに何が増えるかを比較する。

## 何をもって確立と呼ぶか

到達段階を三つに分ける。

1. **幾何学的な成立：** 指定範囲で正しい投影を作れることを導出し、基準例と境界で検算する。
2. **手順としての整備：** 指定道具で入力から描画まで進める説明、例、誤差と適用外がそろう。人の実施確認前はここまで。
3. **利用上の確認：** 人が実行した記録から、完遂・時間・誤差を確認する。広い対象への容易さや学習効果は、さらに対応する比較・保持・転移の検証を必要とする。

第1〜6段階の自律作業の完了条件は、正確な方法を少なくとも1つ一般姿勢へ対応させ、もう一つの独立した方法と共通条件で照合し、省力化・近似を採否判断し、手順書と保留一覧まで作ることとする。近似の採用がゼロでも、条件と比較結果に基づく見送りなら完了できる。

数学的成立が確認できても、メソッドを自動的に `stable` に移さない。[既存の評価方針](evaluation.md)に従い、何を確認した採用判断かを明記する。

## 調査を広げる条件と止める条件

追加調査は「未解決のどの操作が変わるか」を先に書く。候補語は `perspective visual ray method cube`、`measuring points three point perspective cube`、`reduced distance inaccessible vanishing point`、`立方体 透視図 測点 距離点 図学`。これらは今後の検索候補であり、実施済み記録とは区別する。

一次の教材・著者の論考・大学公開資料を優先する。取得できない資料は、既存の確認範囲、取得失敗、再開条件を残す。ログイン・資料購入・人への提供依頼を必須の依存にしない。既存の公開資料と独立導出で基準法を進める。

一般的な箱の描き方だけで、立方体の実長や画面条件が不明な教材は補助資料にとどめる。古典の焼き直しを新発見と呼ばず、独自の貢献が手順の短縮、誤差範囲、選択表のどれなのかを明示する。

同じ失敗を繰り返す案は、入力条件を修正できるか、一つの反例で一般性が失われるかを記録して見送る。検索件数や作図例の枚数を増やすこと自体を成果にしない。
