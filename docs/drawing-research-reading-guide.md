# 疑問から読む描画研究ガイド

2026-10-02。資料・図・合成課題を目的から引くためのガイドです。悩みの原因や個人の技能を診断する分類ではありません。まず関連する操作を選び、資料の確認範囲と未解決点を読んでください。用語は[用語集](glossary.md)へまとめています。

教材の手順は「著者がどう教えているか」、研究は「その対象・比較条件で何が起きたか」、作家の回想は「本人がどう振り返ったか」を示します。効果の根拠を確かめる場合は[主張台帳](../research/comparisons/drawing-claim-ledger.md)へ戻れます。

## 厚みが分からない

関連操作は主要な量、面と軸、断面と曲面です。読む順は[操作別比較と図1](../research/comparisons/figure-abstraction-operations.md) → [体幹の箱の意味](../research/comparisons/torso-construction-worked-comparison.md) → [洞田の第3回](../references/artists/toda-kobun-method.md)。

量を置くこと、向きを指すこと、曲面に回り込みを示すことの違いが分かります。洞田は指定本文・図を確認済みですが、図解は一部を省いた独自の説明です。箱の厚みが決まっても人体の表面が一意に決まるわけではありません。リクノの未取得定義の代用にはしません。

対応する素材は[箱と円柱・参照ありA](../assets/construction-geometry/prompts/box-cylinder-T1-A.md)。真円柱ではなく24角柱の既知のモデルで、輪郭と固定目印を区別できます。人体の正しい厚みや練習効果はこの課題では答えられません。

## 胸と骨盤の向きを混同する

関連操作は面と軸、二つの量の相対配置です。[体幹比較](../research/comparisons/torso-construction-worked-comparison.md) → [ProkoのMotion・Twist](../references/videos/proko-robo-bean-and-obliques.md) → [操作別比較](../research/comparisons/figure-abstraction-operations.md)の順に読みます。

同じ「箱」でも表す範囲が異なること、二量を別々の向きとして扱うことを確認できます。ProkoはLesson Notesと指定図3点までで、動画の筆順は未照合です。洞田の補助箱をProkoの骨盤の箱へそのまま移せません。

対応図は[向きと接続の図](../assets/figure-abstraction-operations/orientation-and-connection.png)、素材は[二箱A](../assets/construction-geometry/prompts/two-boxes-T1-A.md)。[軸方向の測定](../research/learning-science/geometric-measurement-checks.md)は画面内の角度であり、三次元の関節角や生体の可動域を教えるものではありません。

## 接続やねじれを見失う

関連操作は量の配置、向き、接続と変形です。[操作別比較の接続行と図2](../research/comparisons/figure-abstraction-operations.md) → [Bridgmanの確認図](../references/books/bridgman-1920-constructive-anatomy.md) → [Prokoの腹斜筋Lesson Notes](../references/videos/proko-robo-bean-and-obliques.md)の順に読みます。

部品を回転させる指定と、間をどうつなぐかが別の判断だと分かります。Bridgmanは指定節とConstruction図版、Prokoは公開Notesの確認範囲です。図から著者の筆順は逆算しません。

対応は[接続帯の独自図](../assets/figure-abstraction-operations/orientation-and-connection.png)と[課題仕様A](../methods/drafts/torso-observation-memory-task-spec.md)。幾何学課題の二箱は間を空けており、接続帯・筋・皮膚の正解までは作っていません。人体のねじれの自然さや動作時の表面変化は未検証です。

## 骨や筋をどこまで覚えるか

関連操作は骨の目印、形の省略、付着と作用、表面変化です。[操作別比較の三つの問い](../research/comparisons/figure-abstraction-operations.md) → [Prokoの目印と腹斜筋](../references/videos/proko-robo-bean-and-obliques.md) → [レオナルド編訳488〜489](../references/books/leonardo-memory-and-functional-anatomy.md)の順で読みます。

形の暗記、つながりや作用の理解、見える面の観察を分けられます。古典は編訳史料であり、現代解剖の全項目を校合した資料ではありません。[Hampton](../references/books/hampton-figure-design-invention.md)は構成・所在を調べる入口で、本文精読済みの手順書としては扱いません。

図は[量・軸・断面](../assets/figure-abstraction-operations/mass-axis-section.png)、仕様は[目印を扱う課題A](../methods/drafts/torso-observation-memory-task-spec.md)が対応します。新しい幾何学素材のIDは骨の名称ではありません。必要な筋名の個数、最適な暗記量、全筋の付着・作用の正解は今回の資料では決められません。

## 見て描けても見ずに描けない

関連操作は観察、同一視点の記憶再生、照合です。[観察と記憶の根拠表](../research/learning-science/observation-memory-feedback.md) → [課題Bの仕様](../methods/drafts/torso-observation-memory-task-spec.md) → [Gonzalezの確認範囲](../references/articles/gonzalez-2011-tracing-copying.md)の順に読みます。古典の手順を知るなら[レオナルド531とSpeed](../research/comparisons/drawing-claim-ledger.md)も入口です。

参照ありの成果と、参照を閉じた成果を分け、修正前後を別に保存する理由が分かります。原著の課題は単純な図形など条件が限定され、人体の記憶練習の優位を直接証明していません。試行数の曖昧さも残しています。

[二箱Bの観察画面](../assets/construction-geometry/prompts/two-boxes-T1-B-observe.md)と[再生指示](../assets/construction-geometry/prompts/two-boxes-T1-B-recall.md)を分けました。記憶力の診断、必要な練習時間、後日の保持への効果は未確認です。図とIDを一緒に覚える条件である点にも注意します。

## 別角度へ移せない

関連操作はモデルの定義、空間内の回転、投影です。[課題Cの仕様](../methods/drafts/torso-observation-memory-task-spec.md) → [幾何学素材のモデル・カメラ定義](../assets/construction-geometry/README.md) → [測定の限界](../research/learning-science/geometric-measurement-checks.md)の順に読みます。

同じ図を思い出す課題と、既知の立体を別視点へ投影する課題を区別できます。[Kim Jung Giの回想](../references/artists/kim-jung-gi-learning-interviews.md)は複数方向の観察の着想になりますが、これらの素材の有効性を示す実験ではありません。

[二箱C・E1](../assets/construction-geometry/prompts/two-boxes-E1-C.md)と[箱と円柱C・E1](../assets/construction-geometry/prompts/box-cylinder-E1-C.md)は完成図を出題に含みません。解答は別フォルダです。平行投影・指定メッシュに正解を限定しているため、未知の人体の裏側、透視投影、自由創作への転移までは答えられません。

## このガイドの点検範囲

6つの入口から資料・図・課題仕様へ到達するリンクと、確認範囲・限界の対応をAIが点検しました。理解しやすさを人が評価した結果ではありません。計画全体の成果・保留・再生成記録は[総括](../research/topics/evidence-and-tools-completion-summary.md)にまとめています。
