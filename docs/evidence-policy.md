# 資料の評価・分類方針

資料の**媒体、根拠の種類、対象分野、確認範囲**を別々に記録します。「有名な先生の教材」「査読論文」「全文を読めた」はそれぞれ別の情報で、どれか一つだけで練習効果を確定しません。具体的な主張の信頼性は、各ノートの「信頼性・適用の限界」で判断します。

## 根拠の種類：evidence_kind

| 値 | 意味 | 読み方 |
| --- | --- | --- |
| `meta-analysis` | 複数研究の効果を統合 | 採用研究の質・ばらつき・出版バイアス・対象課題を点検する |
| `review` | 研究のレビュー・理論整理 | 系統的レビューか、論者の選択による総説かも本文で確認する |
| `controlled-study` | 条件・群を比較する研究 | 無作為割付の有無を本文に明記。非無作為比較も含み、同じ強さとは扱わない |
| `observational-study` | 観察・相関・事例分析 | 関連や過程を知る資料。因果的な練習効果とは区別する |
| `methodology` | 測定・研究計画の方法論 | 評価を設計する資料。特定の練習法の効果を示すものではない |
| `practitioner-method` | 本人・公式教材が提示する指導法 | 手順の出典として有用。効果を支持する比較データの有無は別に確認する |
| `anecdote` | 体験談・成功例 | 仮説のきっかけ。失敗例・脱落者・他の練習の影響を把握できないことが多い |

単純な点数順にはしません。質の低いメタ分析が、適切な一つの実験より常に優れるわけではありません。また、論文中の個人の意見まで実験結果として扱わないでください。人気・再生数・推薦者数は根拠の分類を上げる材料にしません。

## 対象分野：domain

`general-learning`（一般的な学習）、`motor-learning`（運動学習）、`visual-perception`（視知覚）、`spatial-skills`（空間技能）、`expertise`（熟達）、`measurement`（測定）、`engineering`（工学）、`architecture`（建築）、`neuroscience`（神経科学）、`drawing`（描画）、`character-illustration`（キャラ絵）などを使用します。

隣接分野のデータは、その分野では有力でも、キャラ絵への効果は**間接的な根拠**です。空間課題、写実的な模写、創作、魅力の評価を同じ到達指標にまとめません。

## 確認範囲：verification

| 値 | 今回実際に確認できたもの |
| --- | --- |
| `full-text-sections` | 本文の指定した節・ページ。全文精読という意味ではない |
| `abstract` | 要旨・書誌が中心。追加で確認した抜粋は本文に記載 |
| `official-description` | 著者・出版社・公式教材の紹介、目次、課題説明。書籍本文や動画全体は未確認 |
| `indexed-excerpts` | 原典の検索エンジン抽出部分。前後の文脈・図表・方法の全体を確認できていない |

確認範囲は信頼度の評点ではありません。検索抽出だけで確認した数値はその経路を記載し、正式な実験設計の根拠として使う前に原文の方法・結果を再確認します。読んでいない書籍、見ていない動画、未確認の図版を確認済みとはしません。

## 主張ごとの判断

1. **何についての主張か**：教材の手順、短期の遂行、保持、転移、長期の熟達を分ける。
2. **誰を何と比べたか**：人数、経験、割付、比較条件、練習時間、評価者を確認する。未確認は未確認と残す。
3. **どれほど確かか**：効果の大きさ・不確実性、交絡、脱落、評価の妥当性、独立した追試を確認する。有意差だけで判断しない。
4. **どこまで適用できるか**：元研究で支持される範囲と、当リポジトリの応用仮説を別の段落にする。

「確認した資料には比較データがない」は「効果がない」とは違います。逆に、作者が上達した、受講者の成功作がある、理屈がもっともらしい、という情報だけで万人に有効とはしません。根拠が弱い方法は、手順が明確なら検証候補として残します。

## 保存と更新

- 出典・公開年・確認日・該当節・限界を残し、同じ研究の出版社版／著者版／PubMedを独立した3研究と数えない。
- 訂正・撤回・追試・反証に気づいたら元ノートを更新し、関連する分析の結論も見直す。
- 練習の**実作業時間、実施期間、頻度、終了から評価までの間隔**を分ける。講座の公開周期は練習量ではない。
- 外部教材は自分の言葉による要約とリンクを基本とする。書籍全文、教材図版、受講者作品をまとめて転載しない。
- `status: ready` は資料メモが読める状態の意味。効果が実証された意味ではない。
