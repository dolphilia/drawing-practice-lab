# スキルマップ

身につける技能を整理するための初期分類です。技能同士は相互に関係するため、全ての基礎を終えるまで人体や構図に進めない、という固定の学習順序ではありません。

```text
fundamentals（基礎）
  観察・比較 / 線 / 形・立体 / 比率 / 遠近 / 明暗 / 色
       ↕                  ↕                   ↕
figure（人体）     composition（構図）    rendering（描写・塗り）
  比率・動き         配置・視線誘導         光・材質・エッジ
  顔・手・構造       明暗・色の設計         色と形の描写

横断する技能：誤差の発見・自己評価 / 記憶からの再現 / 制作への応用
```

## 分類の使い方

- 技能文書には「何ができるか」、ドリルには「どう練習するか」を書く。
- 明暗の基本理解は `fundamentals`、画面全体の明暗設計は `composition`、材質や光の描き分けは `rendering` を主な置き場の目安にする。
- 観察・比較・自己評価は、まず `fundamentals` と各ドリルの評価欄で扱う。
- 背景・動物・デザインなどは、当面は主な技能の分類に置き、タグで横断的に探す。文書が増えたら分類を分ける。
- 必須の前提がある場合だけ `prerequisites` に登録する。単なる関連技能は `related` に入れる。
