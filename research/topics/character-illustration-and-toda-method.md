# キャラ絵の技能分解と洞田創のメソッド

## キャラ絵の到達目標を分ける

「キャラ絵が描ける」は一つの技能ではありません。次は、このリポジトリでメソッドを開発するための分解案です。科学的に標準化された能力尺度ではありません。

| 技能 | 今回の教材候補 | 評価課題の案 |
| --- | --- | --- |
| 頭部・全身を立体として構築する | [トダ式](../../references/artists/toda-kobun-method.md)、[Loomis式頭部](../../references/videos/proko-loomis-head.md)、[パース](../../references/books/robertson-2013-how-to-draw.md) | 未見角度での向き・接続・比率を、指定した作風の基準で見る |
| 動き・演技を伝える | [ジェスチャー](../../references/videos/proko-gesture.md)、[シルエット](../../references/articles/clipstudio-silhouette-poses.md) | 説明なしで意図した動作が読み取れるか |
| 同じキャラクターを保つ | 構築法と[形の比較](../../references/articles/clipstudio-copying-shapes.md)を組み合わせる案 | 別角度・別表情でも、事前に定めた特徴が維持されるか |
| 設定を外見へ落とし込む | [キャラクターデザイン](../../references/articles/clipstudio-character-design.md) | 同一設定から複数案を作り、意図の伝達と違いを評価する |
| 配色・描画工程を扱う | [ガマットマッピング](../../references/articles/gurney-2013-gamut-mapping.md)、[Ctrl+Paint](../../references/videos/ctrlpaint-library.md) | 指定した明暗・配色意図を別のシーンでも実現できるか |
| 弱点を特定して練習を更新する | [さいとうなおきの教材](../../references/books/saito-2022-fast-improvement.md) | 比較→一つの修正→再制作の記録が、選んだ指標の改善につながるか |

魅力・好みは観者や文化、目的によって変わります。万人共通の正しい顔の比率を置かず、写実的な正確さ、狙った変形、受け手の好みを分けます。

## 洞田創さんの方法について確認できたこと

本人の2015年講座では**広文メソッド**と呼ばれ、関連する講座一覧には**トダ式アタリ**の呼称もあります。[資料ノート](../../references/artists/toda-kobun-method.md)に全15回の所在・本文確認と、指定図版6点の照合記録を保存しました。未確認の図版が残り、全工程を再現した手順書ではありません。

円・箱と比率を使って全身のアタリを組み立て、説明を見ながら作業できる教材です。ただし、比率を厳密に固定するという理解では不十分でした。導入時の簡単な配置から、段階に応じた修正、作風に合わせた変更、実物や資料を参照する下書きへ進みます。以下はこの確認から導く当リポジトリの評価設計上の判断です。

| 区別する段階 | 評価で混ぜないこと |
| --- | --- |
| 初期素体の作図 | 選んだモデルの向き・接続と、写実的な人体の正しさ |
| 改良素体への変更 | 初期配置の記憶違いと、教材が指示する意図的な変更 |
| 下書き・着衣 | アタリへの一致と、参照資料・狙う作風に応じた輪郭修正 |
| 別角度・別体型 | 教材で扱った例の再現と、教材で解決していない条件への転移 |

数値の端点や本文訂正を確認してから採点基準に使います。図版の誤記をそのまま正解とすることや、初期モデルの値を最終絵へ要求することは避けます。公開15回という構成から必要練習時間や到達期間は推定できません。

## 信頼性の判断

- **手順の出典**：本人の説明があり、誰の方法か追える。
- **学習効果**：今回確認した記事には、対照群・受講者全体の分布・脱落・後日の保持を評価するデータは確認できない。これは方法が無効という意味ではない。
- **適用範囲**：特定のデフォルメを含む構築法であり、著者が認める比率変更を含め、別体型・年齢・作風へ適用できるかは別に調べる。
- **説明の扱い**：ブログの大学・研究室という呼称や、数値化された手順を、科学的な検証の証拠としない。左右脳の表現にも独立した効果の根拠を求める。

## 開発につながる仮説

「完成した人体を頭の中だけで保持する負担を減らし、紙面上で少しずつ構築できる」という解釈は有望です。ただし認知負荷の軽減を実測したものではありません。[建築スケッチとの比較](cross-domain-transfer.md)も、共通する可能性を考える材料です。

最初の探索では次を分けて記録します。

1. **手順参照あり**：指定した比率・向きのアタリを制限時間内に作れるか。説明のどこで止まったか。
2. **後日の保持**：手順書を外したときにどの部位・接続が崩れるか。描画資料の参照可否は別に決める。
3. **近い転移**：未練習の角度で同じ構築を使えるか。初回から難しい角度だけをテストにしない。
4. **別体型への変更**：比率を変更したときに再構築できるか。元教材の固定値を守る点数とは分ける。
5. **完成絵への転移**：衣服や演技を加えたとき、アタリの利点が残るか。完成度だけでなく所要時間と修正も残す。

この順序は当リポジトリの検証案であり、著者が指定した実験計画ではありません。日程・分数は[評価時期の整理](../learning-science/practice-dose-and-evaluation-timing.md)を参照し、結果を得る前に `stable` にしません。

## 次の狭い問い

「胴体の同じモデルを組み立てるとき、手順参照の可否で接続・向き・所要時間がどう変わるか」を候補とします。参照を外す条件は教材本来の使用条件より難しくなるため、手順なしで失敗しただけで教材全体を無効と判断しません。説明の読解、補助線を描く時間、修正の時間も実描画と分けます。

これはまだ実験計画ではありません。第3回の残りの図と第7回の照合後、対象モデル・題材・採点の端点を定め、[描画評価候補](../learning-science/drawing-assessment-candidates.md)の測定のぶれを確認する段階へ渡します。実験の分数・期間を講座回数から埋めないことも条件です。

## 追加で確かめるべきこと

表情、手足、衣服、キャラクター同一性、デフォルメの設計、完成作での演技については今回の収集だけでは薄い状態です。今回の構築教材をキャラ絵全体の完全なカリキュラムとせず、今後は各技能の公式教材と、受け手の判断を測った研究を別々に収集します。
