# 立方体の作図研究で共有する入力と正解

## 入力を固定する

単位はmm、辺長a、中心C=(Xc,Yc,D)、画面距離f、紙上倍率mとする。視点座標は右X・上Y・前Z。画面はZ=f、紙上の原点は視線と画面の交点である。紙の左右±90mm・上下±125mmを比較範囲とする。fとmは別の入力欄に保存し、中心距離Dと取り違えない。

初期比較ではa=60、f=100、m=1。Dは120または240。位置はC=(0,0,D)または(0.3D,−0.2D)。24条件と12境界条件は[cases.json](../../assets/cube-projection-research/cases.json)で固定した。最大座標誤差1mmを選別の中心値、0.5・2mmを補助値とする。これは設計値であり、人が許容できる誤差の実証値ではない。

### 角度の順番

立方体を視点座標の固定Y軸でα、続いて固定X軸でβ、最後に固定Z軸でγだけ回す。各段階で、左辺にはその段階の新しい値、右辺には段階開始時の値を使う。

```text
α：X1 = ca X0 + sa Z0    Y1 = Y0    Z1 = −sa X0 + ca Z0
β：X2 = X1              Y2 = cb Y1 − sb Z1    Z2 = sb Y1 + cb Z1
γ：X3 = cg X2 − sg Y2    Y3 = sg X2 + cg Y2    Z3 = Z2
```

cはその角度のcos、sはsinに相当する円の横・縦成分。人は関数電卓を使わず、[手順書](../../docs/cube-construction-manual.md)の円の読み取りで用意する。立方体の中心を回すのではなく、中心からの半辺だけを回し、最後にCを足す。

この符号では**βが負だと上面を見せる向き、正だと底面を見せる向き**になる。計画の候補値にはその符号が未定だったため、基本姿勢を(0,0,0)、(30,0,0)、(45,−20,0)、(65,35,15)、(15,−70,30)、(0,−90,0)に確定した。B03はβ=90。これは俯瞰・あおりの意味をそろえる修正で、条件数や研究範囲は変えない。

一般の相対姿勢をこの3回転で表せる。極位置では角度の表現が一意でなくても、指定した回転を順に適用した位置は定まる。逆に図から角度を推定する問題は今回の基準入力とは別である。

初期半辺h1=(a/2,0,0)、h2=(0,a/2,0)、h3=(0,0,a/2)に上の回転を行う。

各点はCに符号付きのh1・h2・h3を足して得る。符号が一つだけ違う点どうしを結ぶ。12辺は01、02、04、13、15、23、26、37、45、46、57、67。例えば01はP0–P1であり、座標値ではない。

## ワールド座標との対応

世界の点をW、視点をE、画面の右・上・前の直交単位ベクトルをr・u・nとすると、X=(W−E)·r、Y=(W−E)·u、Z=(W−E)·n。逆変換はW=E+Xr+Yu+Zn。全ケースで非自明なE=(13,−17,29)、r=(0,1,0)、u=(−0.8,0,0.6)、n=(0.6,0,0.8)を保存した。特定の世界の軸と視点の軸がたまたま一致するだけの検査にしないためである。

人が世界の位置から始める場合は、W−Eを取った後、視点の向きを作った回転を**逆順・逆角度**で適用すれば同じ視点座標になる。視点の向きをY→X→Zの回転で指定したなら、逆変換はZの逆回転→Xの逆回転→Yの逆回転。半辺にも同じ逆回転を行う。三つの単位軸が与えられている場合は上の内積を四則演算で計算できる。

「注視点だけ」から始める場合、前方向nは注視点−Eをその長さで割って得るが、上方向がまだ不足する。右方向の基準をもう一つ指定し、nと直交するようにする必要がある。今回は余分なベクトル正規化を初学者へ要求せず、視点の向きを3角度または直交軸として指定する入口を採用する。真上・真下でもγを指定するので上方向が曖昧にならない。

入力検査は単位タグ、回転順序、必須欄、未知の欄、正の辺長・f・m、有限値、視点軸の直交性・向きを検査する。利用者がDとfの正の数値を意図せず入れ替えた場合、その意図までは自動検出できない。欄の説明と既知例による確認を併用する。「向きを混同するすべての誤入力を検出できる」とはしない。

## 正解の独立した求め方

数値経路は3本の半辺を順次回転し、各頂点をu=m f X/Z、v=m f Y/Zで投影する。

独立経路は、姿勢をクォータニオンで合成して世界の頂点Wを求め、世界座標でE+t(W−E)=E+fn+ur+vuの連立一次方程式を解く。回転生成も投影の計算も、数値経路と同じ関数を再利用していない。その後mを掛ける。

紙上の視線法は、横座標Z・縦座標Xの補助図と、横座標Z・縦座標Yの補助図で、視線とZ=fの直線を2次元の交点として解く。数学的には同じ中心投影を別の操作列で構成したもの。実装上の一致だけで一般性を証明したのではなく、各三角形が相似であることから式を導く。

## 適用外と検査結果

Z≤0を含む場合は通常の8点作図を拒否する。機械では長さの丸めに対し1e−9mmの境界許容を用いる。全点が正でも紙外なら `outside-paper` として値を保持し、黙って拡大縮小しない。B09・B10は拒否、B07・B08・B11は紙外、その他は紙内となった。

[検査コード](../../assets/cube-projection-research/test_geometry.py)は、36条件、200個の別途生成した一般姿勢、直交・等長、既知の正面の分数値、画面距離と対象距離の違い、世界座標の不変性、不正入力、補助図縮小、画面内回転を確認する。[正解座標](../../assets/cube-projection-research/reference-results.json)には判定と8点を保存した。有限34条件の独立経路・紙上視線・測点の最大不一致は1e−7mm未満。実測精度を意味しない。
