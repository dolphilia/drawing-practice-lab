# 意図的練習：定義・訂正・評価を分けて読む

## A4の判断

「意図的練習」という名前だけでは比較する活動が決まらない。2018年の数式訂正、2019年の研究の再選別、測定の不確かさを補う補正を区別する。描画の最低練習時間を導く資料としては使用しない。

| 資料・操作 | 今回確認したこと | 本リポジトリでの扱い |
| --- | --- | --- |
| [Macnamara 2014と2018年訂正](../../references/articles/macnamara-2014-deliberate-practice.md) | 従属効果量の調整を訂正 | 引用は訂正後の値を使用。採否への論争と区別 |
| [Ericsson & Harwell 2019](../../references/articles/ericsson-2019-practice-definition.md) | 定義・対象成績・個人練習の条件で再選別し、信頼性を仮定して補正 | 対象と仮定が異なる推定。元研究と独立した証拠として加算しない |
| [Hambrickほか2020](../../references/articles/hambrick-2020-deliberate-practice-critique.md) | 定義の一貫性への批判と補正の感度分析 | 反証候補として保存。論評の数で決着をつけない |

数値・確認箇所は各ノートに集約した。統計的な関連の大きさと、ある人に練習を追加したときの改善量は別の問いである。低い説明分散から練習の無効を、高い説明分散から誰でも到達できることを判断しない。

## 描画の比較に渡す運用案

以下は当リポジトリの設計案で、有効性が検証された描画メソッドではない。

| 記録する項目 | 具体例・判断の仕方 |
| --- | --- |
| 目標と評価課題の対応 | 顔の向きの構築を練習したなら、まず未見の向きでの構築精度を測る。完成作の魅力は別の転移評価 |
| 課題の選択と個別化 | 自分が選んだか、教材の共通課題か、講師が現在の誤りに合わせて選んだか |
| 修正できる情報 | 何を基準に誤差を知り、次の試行でどこを変えたか。添削者・参照資料・補助の有無も記録 |
| 実施量 | 実際に描いた分数、説明・視聴、添削、評価の時間を分ける。回顧的推定か当日記録かも残す |
| 条件を守れたか | 予定した手順と逸脱を記録し、結果を見てから成功例だけを練習群に分類し直さない |
| 評価の独立性 | 練習に使った基準だけに過度に適合していないか。保持・未見題材・採点のぶれを別途確認 |

例えば「トダ式の顔の比率を参照して反復する」と「添削者が個人の誤りに応じて課題を変える」は、同じ練習時間でも異なる条件として記録する。どちらが有効かは現段階で判断しない。講師の有無だけで練習の質を認定しない。
