# 洞田式の胴体構築から切り出す測定課題：基準箱と補助箱

## 問いと位置付け

**基準箱と補助箱の高さ関係を、同じ作品から安定して測れるか。** まず採点手順の試行対象を定める。手順参照の有無による学習効果の比較は、その後の別段階とする。

[洞田講座の第3回の図](../../references/artists/toda-kobun-method.md)では、胸郭の下へ補助箱を置く。ここから高さの関係だけを切り出し、**正面・平行投影・傾きとひねりなしの二つの基準箱**に簡略化する。以下の仕様は当リポジトリの独自案で、著者の公式課題でも、検証済み尺度でもない。現段階では試行用画像・実作品を用意しておらず、測定・練習とも未実施。

## 原典の操作と評価側の制約

| 論点 | 原典で確認したこと | この測定案での扱い |
| --- | --- | --- |
| 胸郭と補助箱 | 胸郭の高さに対する補助箱の高さの目安がある | 胸郭の切断前の基準箱を残し、高さの測定点を明示する |
| 奥行きと傾き | 立体としての分割、回転、ポーズに応じた短縮を含む | 最初の測定では除く。任意の透視図に同じ画面上の比率を要求しない |
| 骨盤・球・くびれ | 選択肢と修正がある | この一つの指標には含めない。全身の構築能力の点数にはしない |
| 手順参照 | 講座を手元に置いてよい | 手順と目標図の参照可否を別々に記録する |
| 描き方の自由 | 目測、簡略化、代替操作を認める | 診断のための条件固定であり、自由な描画の失敗判定に使わない |

## 課題仕様の草案 v1

対象は消せる筆記具またはレイヤーを使って線を区別できる成人の初心者〜中級者を想定する。技能水準の判定は未実施。

1. 評価用原図は、同じ幅の上下二長方形とする。上の高さをH、下を0.75Hとし、辺を共有して縦に並べる。上が胸郭を作る前の基準箱、下が補助箱の正面投影に相当する。これは測定を分離するための独自の簡略化である。
2. 原図は傾けず、描画用紙／キャンバスの縦横と平行にする。描画も同じ向きに指定する。斜め視点の教材画像の縦横を定規で合わせる課題にはしない。
3. 基準線を消さず、描き直したときは最終採用の辺を本人が指定して保存する。採点時に一番よい線を採点者が選び直さない。候補が複数残って採用線を決められなければ「線の特定不能」とする。
4. 測定の試行では原図を見て描く条件を固定する。手順参照、定規・グリッド・スナップ・変形機能の使用は別欄で記録し、条件を混ぜた集計をしない。
5. 全体の大きさは主指標の対象外とする。画面／紙のサイズと原図の表示寸法は試行開始前に固定する。下の箱の幅、線の質、人体らしさ、所要時間を高さ誤差へ混ぜない。

この仕様だけではまだ実施版ではない。原図ファイル、提示文、描画寸法、画材、時間上限、作品数、再採点間隔、実用的な改善幅が未確定である。開始前に別の実施計画へ値を固定する。

## 測定点・式・欠測の扱い

上箱上辺の左右端をA・B、共有辺の左右端をC・D、下箱下辺の左右端をE・Fとする。端点は採用した辺の中心線が縦辺と交わる点とする。線幅・角の丸みで一意に決められないときは、推定で埋めずその箇所を記録する。

画像の下方向を正のy軸とし、各辺の両端のy座標の平均を `y_top`、`y_join`、`y_bottom` とする。紙の写真を使う場合は撮影の台形歪みや紙の傾きを含めない取り込み方法を先に定める。原画は保存し、後から作品ごとに異なる補正をしない。

```text
h_upper = y_join - y_top
h_lower = y_bottom - y_join
ratio = h_lower / h_upper
signed_error = ratio - 0.75
absolute_error = abs(signed_error)
```

主指標は `absolute_error`（無次元、比率の差）。方向確認用に `signed_error` も保存する。0.10は比率の差0.10であり、「描画技能が10%悪い」という意味ではない。原図で式を計算して0になることは式の整合性の確認で、採点の信頼性の実証ではない。

| 状況 | 記録・集計 |
| --- | --- |
| 六つの端点を特定でき、両方の高さが正 | 座標と比率を保存。丸めは最終表示時のみ |
| 箱・辺の欠落、採用線不明、線の交点不明 | 比率は欠測。理由と作図の未完了を別欄に残す |
| `h_upper <= 0` または `h_lower <= 0` | 箱の順序／退化の不成立として欠測。0点や誤差最大値に置換しない |
| 視点変更・回転・撮影歪み等で同じ投影条件にない | 条件逸脱として保留。見た目を合わせる補正で救済しない |
| 時間上限で中断 | 実時間・中断理由・完了状況を保存。測定可能なら途中値として別扱い |

欠測を捨てて平均だけ示すと、難しい作品が見えなくなる。全作品数、測定可能数、欠測・中断の理由を併記する。現時点で合格点や最小改善幅は設定しない。

## 採点のぶれと作画のぶれを分ける

[描画の評価候補](drawing-assessment-candidates.md)の方針をこの課題へ適用する。

- **同じ作品を再採点**：IDと順番を変えて六点を再指定し、比率の差・端点のずれ・欠測判定の一致を見る。匿名化しても自作を思い出せる限界は残る。
- **別の作品を描く**：別日に同じ条件で描き、制作時の変動を見る。採点の再現性と同じ数値にはまとめない。
- **採点手順を変える**：端点規則を改訂したら版を上げ、旧版と新版の値をそのまま前後比較しない。

Koo & LiのICCを機械的に計算する段階ではない。少数作品の一致や狭い点数範囲の問題を踏まえ、採点差そのものと欠測を先に示す。必要な作品数・採点者数と、改善幅を区別できる測定精度は段階Bで判断する。

記録欄の案：作品ID、仕様版、制作日時、画材・寸法、目標図参照、手順参照、補助機能、説明時間、作画時間、修正時間、完了状況、採点者、採点回、六点の座標、比率、欠測理由。修正時間を作画時間に含めたかを明記し、二重計上しない。

## 保持・転移へ進むときに分けること

同じ時点で手順あり／なしを比べても、それだけでは学習効果や保持を示さない。保持は最終練習から評価までの時間を置き、練習直後と同じ参照条件で比較する。目標図を残した場合に測れるのは、目標を参照した作図の保持であり、体型の記憶ではない。

目標図も外す課題は別条件として扱う。未見角度への転移では投影によって画面上の比率が変わるため、この0.75基準を流用しない。骨盤接続・ひねり・完成絵への転移にも別の課題と採点を要する。[評価時期の整理](practice-dose-and-evaluation-timing.md)の日程例を必要最低期間とはしない。

## 段階Bへの引き渡し

次に調べるのは、繰り返し採点と繰り返し描画を分けた研究、測定点の定義、採点差と改善幅の関係、保持時の補助条件である。既存のMerzdorf・Chamberlain・Liuおよび測定方法論を起点にする。研究でこの独自課題が妥当化されたとは扱わない。

実作図で上限・下限に偏る、同じ比率でも接続の誤りが多い、再採点で点の選び方が定まらない場合は、より複雑な効果実験へ進む前に課題を見直す。方法比較の最初の問いは、測定案が成立してから別途定める。
