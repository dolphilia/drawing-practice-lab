# 同技能比較：指定比率の分割とグリッド模写

## 同じ技能へ絞る

[洞田講座第3・7回](../../references/artists/toda-kobun-method.md)から上下箱の高さ比0.75だけを切り出す。[CLIP模写](../../references/articles/clipstudio-copying-shapes.md)の画面三分割・外形観察を、同じ箱図形の模写へ適用する。人体全工程や教材全体を競わせる比較ではない。原著者が提案した比較実験ではなく、このリポジトリによる課題化である。

| 条件 | 比率を分割する候補 | グリッド模写候補 |
| --- | --- | --- |
| 入力・目標 | 同じ正面図を見て上下箱を描く | 同じ図を見る |
| 手順 | 上箱の高さを半分、さらに半分に考え、下箱をその3区間とする | 原図と作画領域を縦横三分割し、外形と境界位置を区画に対して比較する |
| 前提・変更 | 独自に2Dへ限定、接続面・奥行き省略。元教材の比率変更・傾きの例外を対象外にする | 元教材の全体外形→形の面の順。三分割そのものは0.75を与えず、区画内の観察が必要 |
| 想定される違い | 上下の内部的な比率関係へ注意を向ける仮説 | 画面上の配置・大きさへ注意を向ける仮説 |
| 評価 | 高さ比誤差、所要時間、欠測 | 同じ指標。位置・大きさの別得点を使うなら双方へ追加 |
| 根拠 | 指導者の構築手順。独立効果未確認 | 指導者の観察手順。独立効果未確認 |

共通評価ではグリッドと手順書を外し、参照図だけを残す。訓練では元の補助を認めるが、説明・補助線・フィードバック時間を含む総時間と実描画時間を両方そろえる必要がある。補助ありの遂行と、補助を外した保持を混ぜない。

最初の[探索計画](../../experiments/2026-10-02_torso-ratio-pilot.md)は比率分割と数値フィードバックを束ねた個人内前後比較で、グリッドとの優劣・機序を識別しない。ここで同技能の手順比較を済ませ、因果的な二方法比較は測定手順の試行後に独立の参加者割付で設計する。不可逆の学習に単純なAB/BAを適用して「洗い流せた」とは扱わない。
